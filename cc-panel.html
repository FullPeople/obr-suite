关于 JSON 与暂时恢复 Excel 导入的说明

Excel 适合把表格摆在纸面上，但角色卡同时包含职业、特性、法术、装备和运行中的数值。依赖固定单元格与公式导入，每次调整表格布局、合并单元格或更新模板，都可能让插件读错位置，也让版本维护越来越困难。

今后为什么统一使用 JSON？

JSON 把每一项角色资料按名称与结构保存，不依赖它显示在哪一格。网站与插件可以使用同一份完整备份，更容易保留条目来源、版本和子内容，也方便及时跟进新的规则与功能。

JSON 是之后优先适配的角色数据格式。长期来看，结构化资料也为不同桌游规则、更多显示方式和平台之间的互通提供了基础；这些是后续发展方向，并不表示目前已经支持所有规则。

你不需要手写 JSON

建议直接到车卡网站创建和编辑角色，完成后导出完整 JSON，再拖入这里、选择文件或粘贴上传。修改后重新导出，用角色旁的 ↻ 更新同一张卡。

旧插件暂时恢复 XLSX 导入，可以选择文件、批量上传、拖拽上传，也可以用角色旁的 ↻ 覆盖更新。支持原有的 2014 / 2024 悲灵角色卡模板，不支持旧式 .xls 文件。JSON 导入继续保留，后续仍建议使用车卡网站；已有上传记录不会因此清除。
