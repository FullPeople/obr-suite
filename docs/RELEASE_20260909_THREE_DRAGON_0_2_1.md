# Three-Dragon Ante 0.2.1-dev

已于 **2026-09-09 17:28（北京时间）** 发布到独立 Dev。[安装三龙牌](https://obr.dnd.center/three-dragon-ante-dev/manifest.json)。27/27 个公网文件核验通过。

## 本次修正

1. 重写四页入门导览：基本流程、选择下注牌、轮流出牌、轮局与整局结算。每页右上角解释当前术语；付款与领出的说明使用较大文字。全局中英文说明改为直接解释规则和操作，沿用原来的矢量龙图与牌背。
2. 悬停时抬牌，移开时直接落回；取消拖拽也直接返回。只有当前合法的本人区域会高亮，非法落点没有落牌光圈。
3. 删除底部文字栏，操作提示和特殊选择放在左下角悬浮气泡。上方横条显示等待名单、当前能力与结算阶段。提示变化不会调整画布或手牌布局。
4. 对手下注、出牌从本人的匿名手牌开始。全部下注后，各自在面前翻牌；最高点数牌（包括并列最高）闪两次，再播放金币进入奖池。全部下注牌均有并列时，不扣金币，弃掉下注牌后重新选择。
5. 公开下注牌保留在对应玩家面前，仍可供后续合法能力取走；不算入其牌阵。术士增加的下注牌放在单独公共区域。奖池显示金币，不显示卡牌框。
6. 教学对手自动行动：余烬在第 2 秒下注；你和余烬都完成后，翡翠再等 1 秒。后续对手出牌和选择能力均自动进行；翻牌结算后再开始下一次 1 秒思考。保留 41 个练习、撤回和重开，隐藏或关闭时暂停并清理计时。

布局调整保持 [Legendary Edition 基础规则](https://wizkids.com/posters/repository/wizkids/3%20Dragon%20Ante%20Rulebook%20WEB.pdf) 的公开下注牌用途：最高点数决定每人付款，最高且无并列者领出，下注牌仍可被规则效果取走。

## 测试清单

已经安装的玩家请完整刷新枭熊页面，然后打开独立三龙牌。

1. 打开“如何游玩”，查看四页文字和右上角术语；切换中英文，并在窄窗口确认可以读完。
2. 进入完整练习局，先等余烬第 2 秒下注，再拖自己的牌。确认翡翠在 1 秒后下注，等待名单逐人减少。另试一次先于余烬下注。
3. 看牌是否从各人的手上落到身前、原地翻开；最高牌闪两次之后金币才移动，之后显示当前出牌者。后续对手不需要按钮推进。
4. 连续悬停、移开、拖起、取消多张牌，确认没有额外向上弹跳。拖向非法区域应回手，只有当前合法区域高亮。
5. 观察提示出现、能力选牌、断线重试时，桌面与手牌是否保持原位置。分别用鼠标、触屏和键盘确认特殊选择可操作。
6. 至少两人实房间游玩，查看对手动作、公开下注牌和金币是否一致；在翻牌中关闭并重开窗口，确认没有重复出牌或扣币。
