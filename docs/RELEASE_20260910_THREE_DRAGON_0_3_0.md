## 本次修改

- 使用用户提供牌包的 100 张正面牌，中文牌名与牌面效果逐项对应。卡背继续使用原单龙矢量图，没有使用 AI 图片或压缩包里的卡背。
- 按用户确认采用牌包规则：湛蓝支配者 8 点、纯白追猎者 10 点、原第六张白龙 7 点，墨绿策划者索取更强的邪恶龙。实际付款、触发与计分使用这些值；普通绿龙仍索取更弱的邪恶龙。
- 新的一轮、轮到谁出牌、新轮局、买牌、组合奖励和整局结束加入中央横幅。计分逐张加点、点数飞入总分、显示特殊加成，再展示胜负和金币分配；平局加轮也先展示比较过程。
- 真实联机的参与者和旁观者共享公开计分报告。能力说明继续由各人点击关闭；断线、重连、窗口关闭及教学回退清理旧展示。教学对手在展示结束后再思考和行动。
- 六页玩法介绍补充强制买牌的时机、定价牌的弃置与付费、补至四张，以及一轮、轮局、整局的区别和结束条件。保留 41 个练习。
- 牌面按需加载，全部正面共 8,940,944 字节。背景进程不加载牌面清单、三维渲染器或教程；纹理回收后不接受迟到的图片回调。

详细规则差异及来源见 [牌包说明](THREE_DRAGON_CARD_PACK_20260910.md)。原图的版权标记保留，不将用户提供的牌面称为项目原创美术。

## 快速测试

**所有玩家完整刷新枭熊页面，然后由任意玩家创建新桌。** 本版采用独立的牌包规则通道，避免旧客户端使用不同数值进入同一桌；旧桌及本地存档不删除、不改写。

1. 检查手牌、公开牌、悬浮详情和能力展示使用新的牌面；暗置牌与牌库继续显示单龙矢量卡背。查看湛蓝支配者、纯白追猎者的点数，以及墨绿策划者要求的选牌方向。
2. 玩过前三轮，确认新轮横幅写出正确的出牌者；结算中每张牌逐步加到总分，特殊加成和赢家分配随后出现。使用“牌阵并列”练习检查先计分、再加轮。
3. 至少两个玩家和一个旁观者测试能力与结算。各自点击关闭能力说明；确认计分一致，并检查返回地图、重新打开或断线重连后没有残留遮罩或旧横幅。
4. 查看玩法介绍最后两页，运行买牌及完整牌局练习：定价牌翻开后弃掉，付费后补至四张；假人自动行动，回退一步后仍可正常出牌。
