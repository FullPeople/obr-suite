# Three-Dragon Ante 0.2.5-dev

已于 **2026-09-10 00:29（北京时间）** 发布。[安装三龙牌](https://obr.dnd.center/three-dragon-ante-dev/manifest.json)。27/27 个公网文件核验通过。

## 本次修改

- 修复真实联机中能力展示被跳过的问题。创建者、其他玩家和旁观者都能看到卡面、牌名与完整效果，各自点击屏幕后关闭。
- 牌桌摘要与私有手牌先后到达时，保留上一次可用状态作为展示依据；同步期间仍禁止出牌。连续更新合并到达时，根据公共记录衔接提取新能力。真正断线、重新打开或无法衔接的历史不会补播旧能力。
- 教程、规则速览及卡牌说明统一使用顺时针／逆时针。三维座位此前反向排列，现与顺时针出牌一致；普通触发比较的是逆时针相邻玩家本轮出的牌。该对应关系依据[官方规则书第 6–7 页](https://eadn-wc03-13179282.nxedge.io/posters/repository/wizkids/3%20Dragon%20Ante%20Rulebook%20WEB.pdf)。规则引擎的座位编号与效果目标未改动。
- 同步整理备用界面的多人座位排列及旁观视角。保留原有矢量图片、点击关闭、音效、手牌回执与创建者开局权限。

## 快速测试

所有参与者完整刷新枭熊页面，使用同一三龙牌版本。

1. 至少两个玩家开局，另一个人旁观。打出能触发能力的牌，三端都应显示说明，超过 1.5 秒仍保留；一人点击后不替其他人关闭。
2. 连续触发能力时逐张点击。需要选择的能力在关闭说明后再选择。断线重连或重新打开牌桌，不应重播之前的能力。
3. 用 3–6 个座位检查轮流出牌，顺序应沿牌桌顺时针。普通能力条件与逆时针相邻玩家比较；黄铜龙向逆时针相邻对手提出要求，绿龙向顺时针相邻对手提出要求。
