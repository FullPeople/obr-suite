# 云端变更通知候选

工作台宿主按当前账号和房间卡凭据订阅云端变更，最多包含 32 个房间范围。通知到达后清除对应卡的读取时间和权限缓存，重新检查权限并读取原卡，再更新角色簿和选中的角色卡。原有定时恢复逻辑保留。

云端编辑权限以后台读取结果为准。尚未核对时保持禁用，DM 身份不能代替卡主授权。读取期间收到新通知会补读，账号、凭据或卡片关联改变后的旧响应不能写回缓存。通知请求只携带范围和游标，不传角色正文；账号退出或关闭页面会取消等待。

本机通知输送与生命周期 5 项检查、类型检查和实际 Chrome 的宿主回归 21 项通过。宿主回归使用实际控制器与卡面代码，SDK 和账号为隔离边界，不能视为真实 QQ 或多人房间验收。记录在任务目录 `evidence/suite-notification-selftest.log`、`suite-notification-types-current.log` 和 `suite-notification-host-browser-regression.log`。

此候选尚未部署；旧枭熊插件的原位云端卡、绑定目录与权限整合仍待完成。
