## 已发布行为与原因

- 点击左上角 Action 历史显示或隐藏头顶结果时，Action 保持打开。原来复用了独立浮窗的关闭通知，现为 Action 使用自己的切换路径；主动关闭按钮和独立历史浮窗行为仍保留。
- 先攻 iframe 原来通过生产适配器直接导入骰子引擎，重复创建同一连接的控制器、Worker 和渲染层。现在 iframe 交给常驻后台投骰，保持每个客户端一套引擎，并防止同请求重发、拆卸后排队执行和外连接请求。
- 原来投骰错误被吞掉，后备计时器仍可能提前写先攻。现在提交失败显示具体原因且不写先攻，后备计时从骰子后台接受并产出结果后开始。
- SDK 普通对象错误显示消息、代码或可读内容，不再只显示 [object Object]。原截图没有 SDK 原始对象，不能声称所有玩家的 network-receive / maintenance 错误都已查明。
