# 源码下载包完整性

检查已有实际源码 ZIP 时，发现手工清单漏掉了该提交已经使用的构建依赖：Suite 缺少公告和界面构建脚本，Web 缺少 Wiki 及正式网站／卡库配置。后来新增的资料验证脚本和配置也容易被同一清单漏掉。原 ZIP、文件列表及散列保留，没有把尚未存在于旧提交中的文件算作旧版缺陷。

两个下载包改为按各自准确 Git 提交生成，包含该提交的完整受控文件。生成前后逐一核对工作文件的原始字节、提交和暂存区；即使 Git 的换行转换把差异显示为已归一，也不能据此打包。源码清单与 ZIP 中的实际文件及其每份原始内容再次完整比较，不能用导出排除规则静默漏掉构建依赖。

本机未跟踪文件、忽略的资料缓存、玩家数据和依赖安装目录不在清单中。只修改源码归档流程，不改变玩家运行代码、资料解析或骰子模式。八项原创检查覆盖完整文件及原字节、未跟踪与忽略文件排除、缺失依赖、换行差异、暂存修改、导出规则遗漏、中文文件名及归档换行转换，全部通过。实际最终配对包、远端 CI 及发布仍分别核对，尚未部署。
