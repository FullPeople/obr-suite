# 独立片尾贡献名单

文字演出增加“片尾贡献名单”预设，使用黑底白字、固定标题、居中向上滚动名单和边缘渐隐。地下城主、冒险者、模组、地图美术、音乐音效和特别感谢均可改写，保存为个人预设后重新打开仍保留。滚动速度、字体和颜色沿用现有编辑器。原默认演出保留。

修复滚动样式静态预览停在名单完全离场位置的问题；停止预览时显示名单开头，实际播放仍从下方向上完整滚动。播放、停止、权限与场景切换沿用原协议，不改变角色、背包或休息资源。

本批在独立工作树从已发布 297 基线实现，不包含另一会话尚未提交的同步、Wiki 缓存与 2D 生命周期修改。仅发布新版插件，配套角色卡和单机网站维持已发布制品；QQ 继续暂停，3D 继续关闭。
