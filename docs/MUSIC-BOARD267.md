# 音乐板 267

音乐板在插件内整理和播放外链音频。工作台只保留一个音乐工作区，不再装载独立 Studio 网页、PeerJS 配对或网站命令。原独立网站的文件和服务不在本次删除或发布范围内。

可添加和编辑名称、直接音频地址、背景音乐／音效、循环、分组、最多六个标签、收藏、颜色和曲目音量。筛选后的背景音乐可一次加入队列，队列支持上下移动、移除和清空；播放历史支持上一首。库容量上限 128 首、队列上限 32 首、同时音效最多四个，实际保存仍受枭熊元数据容量限制；容量不足原子拒绝，不删掉现有条目或其他模块数据。

固定播放控制区与可滚动曲库分开。小窗口使用曲库／队列高亮切换和紧凑导入导出按钮，无下拉选择。外链需为可直接读取的 HTTP／HTTPS 音频；不处理本地音频上传、压缩或 APNG。默认曲库在主动点击后读取外链清单。

曲库保存到当前房间，沿用单写者、实时身份与角色权限检查及请求去重。共享保存失败时保留原状态，不自动重放；播放锚点、CORS 重试、音效压低背景音乐和渐变停止沿用现有后台播放器。每首音量乘以个人、房间和音效压低增益。编辑收藏曲目时不改动正在播放的快照。

支持带名称的链接列表、JSON 文件和旧 `obrm1:` 分享码；整批校验后显示预览，再选择合并或替换。替换和编辑携带曲库版本，队列调整携带队列快照，过期修改拒绝写入。JSON 导出保留外链、标签和所有曲目设置。

后台按房间在本机保存当前与上一版曲库备份，仅曲库改变时更新。恢复先打开导入预览，不自动覆盖。未保存的新曲目草稿和个人音量留在本机。关闭、缩小、重新打开控制面板不销毁后台播放器。

## 验证边界

较大的曲库、导入命令和备份响应按枭熊单条消息 16 KB 的约束分段，最多 64 KB。分片保留 SDK 的发送者身份，缺片、重复片、乱序与不同发送者混用不提交半批内容；关闭订阅会清理未完成消息。进度更新不重复发送未变的曲库。

八组曲库转换检查覆盖旧格式、整批拒绝、导出重入、容量、过期修改、播放快照、队列与历史。既有多客户端模拟覆盖单写者、权限即时撤回、迟到命令、换场景、存储配额和音频退役/CORS，并保留五个破坏性反向检查。

实际浏览器运行生产后台、控制界面与真实 WebAudio，在跨来源父页面的两个框架中验证无本机声音许可的自动下一首、音量隔离、关闭/缩小后的持续播放、暂停/继续、编辑筛选收藏、导入预览/合并、JSON 下载、上一版备份恢复、重开持久化、只读权限、113 首曲库的大消息导入/显示/备份与桌面/320 像素浅深色布局。SDK 与房间为模拟边界，不等于真实枭熊多人或实体设备验收。

仅计划发布 `/suite-dev/`。其他网站、旧插件、原独立音乐网站和后端保持保护，发布前核验最新来源、精确提交 CI、当前线上基线与完整恢复点。
