# 第二轮 dev 测试清单

目标版本：Full Suite **1.0.150-dev**；独立三龙牌 **0.1.0-dev**。实际发布与在线指纹以 [本轮发布记录](DEV_RELEASE_20260909_FEEDBACK.md) 为准。

准备：使用一个测试房间、一个 DM 和至少一个玩家。房间只安装一个 Full Suite 通道；本轮使用 [Full Suite Dev](https://obr.dnd.center/suite-dev/manifest-dev.json)。双方完整刷新枭熊页面，音乐网站也刷新。需要测牌局时，由 DM 在房间安装 [三龙牌 Dev](https://obr.dnd.center/three-dragon-ante-dev/manifest.json)，不需要另开牌局服务器。

已于 2026-09-09 14:01 北京时间上线。独立三龙牌使用自己的存储，旧 Suite 内的牌局不会自动迁移；本轮请新开测试局。

## 1. 音乐（先测这个）

- [ ] 配对音乐网站与枭熊，加载一首音乐。分别在网站、DM 音乐板、玩家音乐板暂停和继续：三处状态一致，听到的声音一致。
- [ ] 暂停时调整循环、拖动进度，再继续；没有意外重新播放、从头播放或进度倒退。
- [ ] **只将音乐网站静音**：网站无声，枭熊仍播放；恢复网站静音开关不改变房间音乐状态。
- [ ] 关闭枭熊音乐控制窗，音乐继续；从网站暂停，再重新打开枭熊音乐板，状态正确。关闭的是整个枭熊页面时，该页面音频应停止。
- [ ] 关闭网站后枭熊继续播放；重新打开并配对后以房间当前状态显示。重复播放同一首、切换歌曲、点音效、停止全部，也无不同步或重复执行。
- [ ] 玩家第一次点击播放若浏览器要求启用声音，按提示操作后可听到；若听不到，记录是 DM、玩家还是网站，及浏览器是否限制自动播放。

## 2. Boss 血条

- [ ] 给一个有 HP 的角色 token 设置 Accessibility 名称，再右键“显示为 Boss”：使用该名称，位于下方居中，背景透明且没有关闭按钮。
- [ ] 在血条覆盖的屏幕区域点击、拖动 token、滚轮缩放，地图照常接收操作；触屏设备也检查拖动与缩放。
- [ ] 同一 token 的普通 HP 条隐藏，AC 等非 HP 信息保留。右键关闭 Boss 后普通 HP 条恢复。
- [ ] 调整普通血条的玩家显示阈值，测试满血、刚好阈值、低于阈值、0 HP；DM、拥有者、其他玩家各自符合原有显示规则。
- [ ] 打开、关闭和拖动常用栏、角色/怪物悬浮窗、状态面板、独立 HP 条、音乐板：Boss 向上避让；没有空位时不遮住控件，并恢复普通 HP 条。也可在 Boss 设置里微调距离底部。
- [ ] 25%、50%、100%、200%、400% 缩放时，Boss 的屏幕位置稳定；同时显示 1～3 个 Boss、连续受伤/治疗、切场景、刷新后没有残留或重复条。
- [ ] 播放转场/CG、打开三龙牌、关闭这些全屏界面后，Boss 显隐、普通条恢复和鼠标操作均正常。这项需要真实枭熊宿主验证。

## 3. 转场与 CG

- [ ] 玩家设置和常用栏没有“转场”按钮，仍能看到 DM 发起的效果。
- [ ] 短休：逐渐黑屏，篝火从下方升起，时钟从上方落下，约 3 秒钟的节拍后各自退回。
- [ ] 长休：帐篷升起；月亮绕下方中心顺时针升起并停顿；随后太阳升起、月亮离开；停顿后太阳向上、帐篷向下离去。
- [ ] 自定义文字：篝火出现，文字在上方渐显、停顿，文字向上和篝火向下离去。
- [ ] 开启系统“减少动态效果”，内容仍可读，结束后正常回到地图；连续点两次、期间切场景也不残留黑屏。
- [ ] MAP、PROP、MOUNT、ATTACHMENT、FOG 等非 CHARACTER 图像能展示 CG；CHARACTER 图像不出现该入口。文字、绘图等没有图片内容的对象不作为 CG。
- [ ] 玩家端先出现黑条，再淡入 CG；结束淡出。慢图片加载、加载中关闭、连续展示两张、断网再重试，都不会闪出旧图或留下不可操作的空白层。DM 保留原来的透视预览方式。

## 4. 传送门、默认预览和已取消入口

- [ ] DM 设置 → 传送门 → 默认图片，从自己的枭熊图库选图。新建单门/一对门均采用它，比例和触发范围正常；重新打开设置仍保存。
- [ ] 原有传送门保留原图；在单门编辑窗“恢复默认”采用房间默认图。“使用内置图片”恢复原图标。
- [ ] 删除或使所选图片不可用时，新门回退内置图标。选择过程中取消、关闭设置、切场景或失去 DM 身份，不发生迟到修改或旧编辑窗回弹。
- [ ] 没有保存过偏好的新玩家默认开启怪物和角色资料悬浮窗；主动关闭后刷新仍关闭。
- [ ] 设置、常用栏、工具栏均没有共享指针功能。

## 5. 独立三龙牌

- [ ] Full Suite 里只有设置介绍与独立安装链接。安装独立插件后，它自己的 action 按钮直接打开全屏酒馆牌桌。
- [ ] 2 人及 3～6 人入座、开局，自己的手牌在下方扇形排列；其他人位于各座位，能看到其牌背的悬停和选中动作，始终看不到私牌牌面。
- [ ] 悬停、键盘聚焦和触摸查看可读规则；选牌之后还需要确认出牌。发牌、出牌落桌有动画，牌堆与公开牌区可辨认；窄窗/小屏上最后一张手牌、确认按钮都可操作。
- [ ] 关闭牌桌、缩小再展开不离席，也不自动出牌。刷新后恢复自己的手牌；主持人关闭整个枭熊页面后其他人收到离线提示，主持人回来后恢复。
- [ ] 开“跟着打一局”，完成固定整局，并各试一个下注平局、同色/同点数航线、欠债、买牌、特殊牌练习。能逐步观察、自己选牌、撤回、重练；教学不影响实际房间牌局。
- [ ] 教学开关、切语言、关闭窗口后没有挡住地图的透明层、重复按钮、旧悬停或旧选中残留。

记录反馈时给出：项目编号、DM/玩家、浏览器、操作步骤、预期和实际表现。血条问题请附地图缩放比例、打开的其他面板及复现用 token；音乐问题请说明是网站还是枭熊端静音/暂停。任何失败项都保持未勾选，自动化通过不代替这份真人验收。
