## 三龙牌

服务器原先只处理显式 `handover`；WebSocket 断开仅删除连接，没有选新主持。现在线上房主的最后一条连接断开后保留 8 秒重连宽限，随后由服务器事务更新主持：已认证在线 GM 优先，其次按座位顺序选择在线玩家。保留牌局、所有手牌、座位、历史和操作回执。多窗口关闭一条或宽限期内刷新不交接；原主持回来不抢回权限。无人在线时保留存档；未获准的连接不能继承。事务失败会保留原状态并重试。

服务器桌隐藏原手动移交按钮；直接离开枭熊房间或关闭最后一个牌桌窗口即触发自动接任。显式离座也保留交接逻辑。断网需先由心跳发现失联，再经过宽限；并非任意断网都能在 8 秒内发现。

范围：当前自有服务器牌桌。仍在进行的旧点对点牌桌保存方式不同，保留其原有安全手动交接；不能在创建者已经离线后凭空恢复仅在创建者处的私有存档。自动交接主持不等于自动代打已离席玩家的回合。

特殊牌无法滚动的原因是 WebGL 牌桌规则将 `.board-scroll` 设为 `overflow:hidden`，同一容器里还有开局设置。新增大厅状态标识，设置区启用纵向滚动，进入牌局后仍按牌桌原布局工作。

## 武器攻击

Web `exportOwlbear` 把 `combat.weapons` 固定输出空数组。完整 native 卡可能仍有武器，但依赖枭熊字段的界面看不到攻击；旧插件的 JSON 归一化同样走这条转换。

卡面和转换现在共用 `weaponAttacks`，保留手工命中、伤害、旧卡额外伤害、装备已有伤害字段、顺序及隐藏选择。完整 native 备份继续保留所有配置。没有擅自推断尚未填写的熟练/属性，也没有引入整套装备自动计算。

用户暂时无法确定旧版还是新版，也没有提供原始文件。已修明确的共享转换缺陷；不能宣称该玩家具体文件已经验收。
