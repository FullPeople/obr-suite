# Three-Dragon Ante 0.3.1-dev

已于 **2026-09-10 04:00（北京时间）** 发布。[安装三龙牌](https://obr.dnd.center/three-dragon-ante-dev/manifest.json)。129/129 个公网文件核验通过。

## 本次修改

- 每位玩家的暗置区固定在其牌阵左侧，两区保持同一深度。两到六人的牌区重新排布；牌阵更宽，卡牌叠放并露出点数角。牌库与弃牌堆始终朝向屏幕。
- 钱币使用用户提供图片中的龙金、碎银，通过常规裁剪与轮廓建模制作。**金币直接放在自己的暗置区，暗置牌压在下面，不加托盘。** 堆高和位置略有错落，金币朝向固定，余额在上方显示；下方公开牌仍可悬浮查看。币堆数量有上限，具体余额以数字为准。
- 桌子改为圆形三维木桌，包含桌沿、软垫、桌裙与底座。没有使用 AI 图片。
- 移除卡牌附加边框，仅保留厚度与阴影。悬浮时右上角只显示原比例的放大牌面，移除重复的规则详解。卡背继续使用单龙矢量图。
- 创建者可以在开局前设置每人初始金币（10–1000）与起始手牌（3–10）。默认仍为玩家人数 × 10 金币、6 张手牌；手牌上限始终为 10。参数经过创建者权限及数值检查，自定义金币总额支持存档恢复。
- 删除桌面详情、弃牌历史、最近记录、玩法速览栏目，保留桌面的实体弃牌堆。如何游玩改为两页：游戏流程与核心规则，重要条件加粗，术语在右上角解释；保留 41 个实开练习。
- 继续使用已确认牌包的全部牌面、中文原文与四处规则差异；联机能力展示、回合横幅和逐张计分过程保留。

## 快速测试

所有玩家完整刷新枭熊页面后打开三龙牌。已有 0.3.0 牌桌和存档保持兼容；要测试开局参数，请创建新桌或返回大厅再开局。

1. 建立六人桌，依次检查每人的暗置区、牌阵及金币归属；翻牌前后金币都在自己的暗置区。悬浮金币下面的公开牌及牌阵露出的数字角，右上角应能查看完整牌面。
2. 检查牌库和弃牌堆一直正向显示，切换玩家视角、调整窗口大小后，暗置区仍在各自牌阵左侧。分别检查两、三、四、五人的布局。
3. 创建者设置 75 金币、8 张起始手牌，开局后所有座位应一致。刷新创建者的枭熊页面，检查恢复后金币、手牌保持一致。普通加入者不能替创建者开局。
4. 打开两页如何游玩，向下滚动阅读每页全部说明；检查买牌条件、8/8/5 前注例子、上家方向和触发时机。进入固定牌局练习，检查对手自动行动及能力展示。
5. 至少两个真人和一个旁观者运行一轮局，检查拖拽、金币转移、能力点击关闭、逐张计分及回合横幅。关闭再打开牌桌，确认没有残留遮罩。
