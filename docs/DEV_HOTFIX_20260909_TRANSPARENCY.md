# 透明展示层黑幕热修

用户在 1.0.150-dev 实测发现：Boss 正常显示，鼠标仍能穿透，但整张地图被黑底遮住。本修复只处理展示页画布，不改牌局、音乐或场景数据。

Boss 根元素强制 `color-scheme: dark`；浏览器在 iframe 外层与文档根元素的实际配色不一致时，会使用不透明画布，即便 html/body 的背景计算值仍是透明。[W3C 的配色画布规则](https://www.w3.org/TR/css-color-adjust-1/#color-scheme-effect)明确规定了这一行为。前一轮只验证了计算样式和鼠标穿透，未检查彩色底图上的实际合成像素，漏掉了该问题。

Boss 展示页恢复默认画布配色，深色表单仅作用于配置窗口内部。转场展示页修复相同问题，并在 HTML 上提前声明展示页面类，防止脚本初始化之前使用控制页底色。CG 保持已有默认配色。

验证采用 Chrome/Edge 两种浏览器、进程级明暗偏好、同源/跨源 iframe，以及三个展示页。normal/light 外层的 48 个实际像素检查通过，原版对照保留。独立设置为 dark 的宿主 iframe 仍有不透明兼容边界，24 例均保留失败像素，不计为通过。曾测试 `light dark` 自动适配，但它在默认外层且浏览器偏暗时依然出现黑幕，已放弃该方案。没有拿 Playwright 全 frame 媒体强制模拟或 Cloudflare 页面冒充真实枭熊宿主。

Boss 的完整行为、配置窗口、鼠标/滚轮穿透和 6 个语义变异回归通过。实际房间最终复测：完整刷新枭熊后保留 Boss 开启，地图应恢复可见；播放短休/长休时只在动画期间出现预期黑幕，结束后正常回到地图。
