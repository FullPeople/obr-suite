# Full Suite-dev 1.0.166 — 同步故障与界面回归修复

本批仅更新 Full Suite-dev；稳定版与独立网页主站保持原版本。代码跨 D:/Desktop/DND-card-web 与 U:/枭熊插件/obr-suite，保留工作区原有未提交修改。

## 修复

- 资源同步：复现了场景 metadata 列表省略自动生命骰/法术位、同时修改自定义资源时，三方合并产生 undefined 资源值，随后读取 name 崩溃的路径。保留派生资源和已消耗次数；远端删除的对象键不会以 undefined 回填。冲突仍报错，不覆盖其他客户端已修改的同一字段。
- 恢复：一个远端 room/card 身份仅保存一个最新恢复草稿，使用 IndexedDB 事务；不再为每个等待回调创建人物副本。角色簿显示房间真实目录，旧缓存、默认空卡和旧未同步备份不混入列表。旧记录未删除，可从角色簿导出本机恢复记录。
- 人物目录：本机身份改为稳定 room/card 键，不再包含浏览器会话。房间保留精简目录，不依赖绑定棋子存在；移除场上棋子或没有加载场景仍能打开角色卡。保存姓名同步目录名。
- 左右布局：投骰与 DM 控制台只替换左侧工作区，右侧 Wiki DOM、条目和阅读状态保留。
- 投骰：构建直接复用 dice-panel.html / panel-page.ts 和 dice-quick-popup.html；没有重新模仿原界面。保留投掷、组合、历史、皮肤、四种二级投骰模式、DM 暗骰及固定结果，通过有明确允许列表的桥访问宿主。无棋子投骰以视口为目标；历史回放重新接到场景；按钮在连接及事件绑定完成后才接受操作。iframe 文档和脚本携带内容版本以免旧缓存。
- 技能整行圆点、加值及名称形成一个悬停/点击/键盘操作区，取消数值下划线。怪物命中/伤害沿用对应动作名称。
- 快捷栏：资源改为单色圆点或数值/进度条，不显示旧资源图片。编辑模式下可拖动武器、固定条目、资源标题进行组内排序或拖出；使用既有自制指针幽灵。自动资源拖出仅隐藏显示，不删除消耗记录；管理界面可恢复。
- 姓名：常态模式下角色名与玩家名只读。
- 规则：基础版本、来源开关、逐条禁用、可选规则、特许记录随角色原生数据同步。自定义扩展定义现在也随人物同步且接受导入校验。此配置按角色保存，不是 DM 强制所有角色采用同一全局规则。来源简写/全称仍属于当前浏览器的阅读偏好。
- 怪物：复用原红色 HP 比例条、粉色临时生命圆、蓝色护甲盾与 GM 锁按钮；修改继续写入原 bubbles metadata，锁控制与原场景生命条一致。不加载怪物头像。

45 项 Vitest 单元检查、4 项纯合并回归、51 项 Edge 浏览器/协议模拟通过。

## 沿用边界
