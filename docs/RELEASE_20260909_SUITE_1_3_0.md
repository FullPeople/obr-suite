# Full Suite 1.3.0 / Dev 1.0.152-dev

本次候选发布按用户要求同时更新稳定版与 Dev。三龙牌的三维牌桌重构独立进行，不混入套件发布；现有三龙牌 0.1.0-dev 与 Music Studio 保持不变。正式上线时间与产物指纹在部署核验后补入本页。

## 本轮修正

- 短休时钟每半秒向前走一格，六格累计转动后保持到退场，摆锤继续左右摆动。
- 圆形图片、元数据检查、状态追踪默认关闭；玩家共享视野默认开启。明确保存过的开关选择保持原值。
- 视野归属合并“自动”与“队伍共用”。共享关闭时为所属玩家，开启时共享给全部玩家。角色卡的详情私密设置不阻止玩家共享视野；隐藏单位、仅 DM 角色与未归属玩家的 NPC 不自动加入。旧 `team` 选择按自动归属读取，不在打开界面时改写场景；DM 放置且尚未归属玩家的光源可在同一菜单指定玩家。
- 设置关闭或恢复模块后，已打开的悬浮栏即时更新。补齐公共状态通知的跨窗口接收，同时修复迟到的角色/状态读取和窗口关闭后的回调。
- 公告改为用户指定的五条更新日志；完整 8/25 旧公告收进默认折叠的历史记录。中文、英文都可查看。
- 稳定版设置中的独立三龙牌地址指向实际已发布的测试版，避免指向不存在的稳定版安装地址。

稳定版同时接收此前 Dev 已发布的透明展示层热修、Boss 血条、音乐板、转场/CG、传送门默认图片和悬浮窗默认开启等改进；细节见 [此前反馈发布](DEV_RELEASE_20260909_FEEDBACK.md) 与 [透明层热修](DEV_HOTFIX_20260909_TRANSPARENCY.md)。共享指针已取消；完整英文角色卡工作簿、角色卡服务器补丁与三龙牌新交互不在本次部署中。

## 核验

- 视野权限与引擎 65 项断言及 11 个有效变异检查通过，光源设置真实浏览器 30 项通过。
- 设置与悬浮栏使用真实产品页面、受控宿主传输运行，9 组跨窗口检查与 2 个有效变异通过；既有状态读取/写入回归 11 组通过。
- 转场/CG 浏览器回归 26 项通过，其中指针在两种语言/视口各采样 23 个时间点，确认离散前进且结束保持。
- 以上不等于真人 Owlbear 房间验收，发布后按下列清单复核宿主表现。

## 简短测试清单

准备：现有用户完整刷新枭熊页面。一个房间只启用稳定版或 Dev 其中一个；请用 DM 和至少一位玩家一起检查。

1. 保持悬浮栏打开，在设置中依次关闭/恢复音乐、转场、时停等模块：按钮马上消失/恢复，不需要重开悬浮栏；玩家仍不显示 DM 转场按钮。
2. 触发短休：指针每半秒向前一格，结束前不归零；动画完全退场，没有残留黑幕。
3. 新房间或未保存对应设置时，圆形图片、元数据检查、状态追踪为关闭，共享视野为开启；旧房间明确保存的选择保留。
4. 打开一个玩家角色的光源设置：只有一个自动归属选项。切换共享开关，选项文字即时切换为所属玩家/全部玩家，输入到一半的范围不丢失。两位玩家分别验证共享与独立视野，隐藏或仅 DM 单位不提供视野。
5. 公告显示五条新日志，8/25 记录默认折叠，点击可展开；切换 CN/EN 内容对应。
6. Boss 血条存在时地图可见，鼠标拖动、缩放正常，玩家显示阈值和普通血条隐藏符合设置；关闭转场/CG 后地图完整恢复。

音乐、传送门图片、CG、Boss 多窗口避让等完整回归继续参考 [第二轮测试清单](DEV_TEST_CHECKLIST_20260909_FEEDBACK.md)。
