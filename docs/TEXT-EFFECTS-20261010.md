# 文字演出候选

“文字演出”是音乐板右侧的独立入口，使用原生枭熊透明全屏画面播放文字和效果。编辑器、即时预览、配置保存和房间播放共用配置与渲染器，不生成 APNG，也没有图片导出步骤。全部效果独立实现，未复制参考网页的程序或素材。

## 使用

1. 打开音乐板右侧的“文字演出”，选择预设或填写标题、副标题和正文。
2. 调整字体、大小、颜色、描边、发光、位置、背景、画面效果及入场／停留／退场时间。
3. 点击“播放预览”在面板中查看完整动画；点击“在枭熊中预览”仅在自己的枭熊画面显示。
4. DM 点击“播放到房间”，向当前场景中的已连接玩家播放。点击“停止本次演出”停止最近一次由本面板发起的演出。

有淡入、上浮、左右滑入、缩放和逐字出现六种入场，以及光芒、雾气、光点、光环和无装饰五种画面效果。默认预设包括战斗宣告、暗处低语、地点字幕、旁白和发现线索。长正文按画面容量分页，标题及副标题会缩小以适应画面。简化动态效果遵循本机偏好；面板预览也可手动勾选。

当前草稿与最多 20 个自定义预设保存在本机浏览器中，关闭面板后可继续编辑。标题上限 160 字符、副标题 240 字符、正文 1,800 字符；入场和退场各最多 3 秒，停留最多 20 秒。自定义预设不上传到房间。

## 播放边界

- 玩家可本地预览和在自己的画面中预览；房间播放及房间停止在宿主中重新检查 DM 权限。
- 演出不遮挡鼠标操作，自动结束；场景关闭时停止，迟到的旧场景消息不重播，新加入的玩家不接收历史演出。
- 同一客户端同时显示一场演出，新演出替换当前演出。自己预览只替换自己的画面。
- 房间消息只携带已验证的文字与效果参数；请求限长、去重，停止按演出 ID 匹配，失败不会自动重复提交。
- 场景元数据仅存放独立的场景标识；不修改角色卡、图像、音乐、房间文档或玩家配置。
