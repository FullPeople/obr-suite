# 骰子闲置生命周期：本地最小修复

基线：`ca684455cef7decacb8bd0d5cffc011b77b500a3`。本候选仅本地验证，未推送、合并或部署。

## 已修复

- 音频 mixer 的所有轨道均暂停后停止 20 ms 调度器；保留轨道，`release` / `retime` 恢复时重新启动。部分轨道仍播放时不会停掉调度器，停止最后一个播放轨道而仍有暂停轨道也能停稳。
- 公开群体目标成功后释放其提交时权限快照。暗骰仍先使用冻结的受众完成封装，不扩大后加入玩家的权限。
- 公开物理/轨迹失败后删除对应请求。群体在分割前或处理中失败时精确清理该提交的子请求及权限快照；原有私密取消、远端拒绝消息和先前已完成结果保留。
- 跟踪物理保留到期和手动取消后的完成回调。`dispose` 取消这两类 timeout，已经捕获但迟到执行的回调也不再操作已关闭对象。原始到期计算与结果完成时间不变。

## 明确边界

本轮没有Edge实机堆快照或GPU测量。已确认的小型JS记录增长和暂停时空转，不能用于解释截图中的几百MB或归因GPU进程。首次预热后的Worker/WASM、材质、音频和有界轨迹缓存保持原设计，没有卸载或缩短任何协议保留时窗。

`dispose` 防线仅覆盖上述两类排定回调；已进入await的其他流程、其他计时器不在本轮完整覆盖。音频正在等待异步加载时发生pause的既有竞态也不在本轮修复范围。因此不能把此候选称为完整hidden/unload生命周期或多端实机验收。
