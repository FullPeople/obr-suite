# Full Suite dev 1.0.149-dev 测试清单

本轮停止新增功能，先验收已实现功能和运行修复。安装地址：

https://obr.dnd.center/suite-dev/manifest-dev.json

## 准备（约 3 分钟）

- [ ] 用一个测试房间，准备 DM + 至少 1 名玩家；最好再加第 2 名玩家。可使用不同浏览器或设备。
- [ ] 房间只安装 **Full Suite (Dev)**。stable 与 dev 共用工具和场景数据，不能在同一个房间同时安装。
- [ ] 已安装 dev 的房间，让每个人完整刷新 Owlbear 页面；在套件的版本信息中确认 **1.0.149-dev**。若仍显示旧版，重新打开房间并核对安装链接。
- [ ] 准备一张小地图、两个分别属于不同玩家的单位，以及一个有当前／最大生命值的 Boss。复杂地图留到基础检查通过后再测。

## 先测能否正常跑团（约 10 分钟）

- [ ] **进入与重进：**首次进房、刷新、退出重进各一次。工具和常用栏出现，页面不一直转圈，不重复出现同一组工具。记录从进入到能拖动单位的时间。
- [ ] **打开界面：**依次打开设置、骰盘、先攻、角色卡、图鉴、搜索。首次和再次打开都能使用；不出现空白页，关闭后能重新打开。记下明显慢的界面及耗时。
- [ ] **开关模块：**DM 在设置里连续关／开一个模块 3 次。最终状态正确；不会出现“开关开着却没有工具”，也不会出现两份窗口。
- [ ] **切场景：**打开几个界面后切到第二场景，再切回来。工具能继续使用；刚才的迟到操作不会写到另一张地图。
- [ ] **原有功能：**投一次普通骰和暗骰，修改一次先攻，给单位加／删状态，打开并编辑现有角色卡。数值正确，玩家权限没有扩大，暗骰不泄露给其他玩家。
- [ ] **骰子图片：**检查骰盘、快捷骰盘、投骰动画、投骰历史及回放。d4–d100 图片不缺失，不显示破图。
- [ ] **编辑保留：**在角色卡或设置中输入尚未保存的内容，让另一端修改无关设置。当前输入和光标不被突然重置；保存后重开内容仍在。

若此组失败，先记录具体步骤，不必继续长局测试。

## 优先验证你关心的体验

### 普通血条与 Boss 血条

- [ ] **缩放错位重点：**分别在地图缩放约 25%、50%、100%、200%、400% 下拖动、平移和修改血量。普通血条始终贴合对应单位，不飘走、不越缩越偏。再试浏览器缩放 80%／125%。请分别记录两种缩放。
- [ ] **复杂单位：**单独拉高／拉宽单位，再旋转、水平／垂直翻转、快速缩放。停止操作后血条应回到正确位置；连续操作不出现明显卡顿。
- [ ] **Boss 入口：**DM 右键有生命值的可见单位 →“显示为 Boss”。DM 与玩家都看到公开血条，伤害／治疗及时同步。
- [ ] **Boss 选项：**设置阶段名、分段、精确生命值；再关掉精确值。各端显示一致。玩家点 × 只隐藏自己一端，在“设置 → Boss 血条”能恢复；降低动画后仍能看清血量变化。

Boss 血条是 DM 主动发布的公开提示，普通迷雾遮挡不会自动保密；需要保密时先隐藏 Boss 血条或隐藏单位。分段不会自动改变血量或推进阶段。

### 视野、传送门和转场

- [ ] **视野默认隔离：**启用动态迷雾，为两名玩家单位设置光源和正确归属。关闭玩家共享视野时，各自只获得自己的视野。
- [ ] **共享开关：**DM 开启／关闭玩家共享视野，玩家画面跟随变化；隐藏单位不额外提供视野。修改归属、切场景或玩家重进后再检查一次。
- [ ] **传送门换图：**创建一对门，在编辑页从自己的 Owlbear 图库选图片；关闭重开、切场景回来仍正确，再恢复默认图。取消选图应保留原图。
- [ ] **独立门特效：**两扇门设置不同效果，其中一个设为无效果。首次拖入就能触发，来回传送时只播放对应效果，不重复弹窗或卡住。
- [ ] **休息转场：**从常用栏“转场”或“设置 → 转场”打开；先预览短休／长休，再由 DM 发给所有人或指定玩家。只有目标玩家看到；结束后能继续操作地图。

休息转场只显示效果，不自动恢复角色卡 HP 或资源。玩家可自行预览，向其他玩家发送由 DM 操作。

### 音乐板与鼠标

- [ ] **启用声音：**每个人打开“设置 → 音乐板”，点一次“启用声音”。用大家都能访问的音频网址或默认曲库，确认各端都有声音。
- [ ] **共同操作：**玩家添加歌曲、暂停、切歌、管理队列，其他端同步；个人音量／静音只影响自己。DM 切为仅 DM 控制后玩家不能再修改共享队列。
- [ ] **关闭后继续：**播放一首至少 1 分钟的歌曲，关闭音乐控制窗口，等 30 秒再打开。音乐持续播放，不从头重播、不出现双重声音；随后测切场景和队列续曲。
- [ ] **共享指针：**玩家选择“共享指针”工具并移动鼠标，其他端看到正确名字、颜色和位置；停止移动或换工具后消失。多人同时指示不会明显拖慢地图。

关闭音乐控制窗应继续播放；关闭整个 Owlbear 页面、关闭音乐模块或宿主卸载扩展后台会停止。浏览器自动播放限制仍要求每个人首次主动启用声音。共享指针只在选中该工具时发送位置。

## 三龙牌全屏牌桌（建议至少玩完一局）

- [ ] **建桌入座：**“设置 → 三龙牌”或常用栏打开牌桌。任意玩家建桌，其他人加入，主持开始；另一个未入座客户端可旁观。
- [ ] **真实牌桌布局：**检查自己的手牌、对手牌区、公共牌区和悬浮大卡。鼠标悬浮可读说明；触屏点击查看。全屏／退出全屏、窄窗口下按钮可点、无内容被遮挡。
- [ ] **隐私：**各玩家只看到自己的手牌，对手手牌保持隐藏；旁观者看不到任何私有手牌。切换为旁观后旧的悬浮手牌也应消失。
- [ ] **打牌与结算：**完成下注、轮流出牌、特殊能力选择和结算；轮到谁、可选什么都清楚，不能重复确认同一操作，金币／牌数不莫名变化。
- [ ] **关闭重开：**玩家与主持分别关闭牌桌窗口再打开，座位、手牌、进度仍在。关闭窗口不等于离席。
- [ ] **主持短暂离线：**主持刷新／短暂离线时其他人收到暂停提示；主持用原浏览器返回后恢复。未明确确认重新开局，不能清空旧局。

规则为 Legendary Edition 基础盒，2–6 人，无扩展。牌局恢复依赖主持人的原浏览器数据。特殊局面若显示规则待裁定的暂停提示，请记录牌面与步骤；这是待完善的边界，不需要强行继续。

## 英文、加载速度与压力检查（基础通过后选测）

- [ ] **切换英文：**设置、角色卡界面、搜索、图鉴、先攻、资源、音乐和三龙牌依次检查。切换语言不清空输入，不跳回错误页面；记录未翻译、截断或难懂的文字。
- [ ] **英文资料：**英文搜索／图鉴能加载正文；分别选择 2014 与 2024 规则，结果不串版。网络失败有可理解的重试入口；重新打开已加载资料不一直重复等待。
- [ ] **角色卡旧功能：**使用原有可用的中文模板或现有角色，下载、打开、上传、绑定、刷新各一次；记录错误提示。工程中的英文 XLSX 尚未作为可上传模板发布，不用拿未完成草稿测试。
- [ ] **慢网恢复：**一端短暂断网再恢复，设置／角色卡／牌桌不一直卡在加载中，旧请求不覆盖新场景或新的权限。
- [ ] **大地图：**在常用的大地图、较多单位和光源下连续玩 5 分钟。记录开关血条／Boss 动画／共享指针前后的卡顿变化，以及首次、再次打开主要界面的耗时。
- [ ] **手机或平板：**选测骰盘、音乐和三龙牌。记录设备、浏览器、横竖屏；部分桌面专用工具在手机上按原设计不显示。

完整英文 XLSX、服务器解析补丁、历史迷雾新方案和平滑跟随研究不属于本次已完成验收项。缩放血条、真实多人同步、原生图库、手机和大地图效果仍以这次实测为准。

## 反馈格式

每个问题给一条就够，不需要整理技术日志：

```text
测试项：例如“普通血条／地图 200% 缩放”
结果：通过 / 失败 / 未测
身份和环境：DM 或玩家；设备、浏览器；大约多少单位
操作步骤：1… 2… 3…
实际表现：发生了什么，等待了多久
预期表现：你希望怎样
重现情况：每次 / 偶尔；刷新后是否恢复
附件：如方便，截图或短录屏
```

最优先反馈：进不了房、界面打不开、数据丢失／错写、玩家看到不应看到的内容、持续卡顿。其他问题可以一并发来；测试期间不继续增加功能。
