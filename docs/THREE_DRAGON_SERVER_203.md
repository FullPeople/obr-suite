# 2026-09-27 · 三龙牌服务器同步（203）

候选版本：Full Suite 1.0.203-dev、独立三龙牌 0.7.17-dev。上线以 RELEASE-203-RESULT.md 的实际回执为准。旧插件、单机角色卡和 Pages 不在本次应用发布范围。

## 改变

新牌桌页面直接连接自有服务器 WebSocket，服务器复用现有纯规则引擎裁定。枭熊保留入口、房间发现、初次身份确认和 GM 权限定期确认；出牌、准备、结算、历史、手势均不再经过 Owlbear LOCAL/REMOTE 广播队列。仅向每位玩家发送自己的私有视图，授权 DM 可查看全能视图。时光龙及原有牌组规则保留。

SQLite WAL 持久化游戏状态、历史和动作回执，成功写入后才确认操作。重复 envelope 或同一动作 ID 不会再次执行。实时历史限量，完整历史另存并按页加载；状态差异更新，手势每 250ms 合并且不存档。离线后自动重连到已保存牌局。主持可以移交后离开。

新身份先获得旁观凭据；服务器不信任客户端自报的玩家 ID/GM。创建者使用枭熊 SDK 的真实 connectionId 对照 party，确认玩家后才允许入座，并恢复已有座位。GM 权限租约 60 秒，在线页面每 20 秒请求复核，失效后撤回私有全能视图。创建者离线时已有普通座位仍可继续游戏；新玩家的首次入座及非创建者的 GM 续期需现任主持在线。离开前使用移交主持。私有令牌只在浏览器及服务器凭据存储中；房间元数据只有邀请信息。

已有旧同步且在大厅/进行中的牌桌继续用旧控制器，避免热迁移破坏当前牌局。旧局结束后刷新牌桌再创建服务器牌桌；已有服务器邀请优先。新旧客户端混用、真人枭熊身份链路及实体手机仍待验证。
