本轮逐项验收：DM 导入后转交编辑权限；海外弱网；状态后切卡、导入卡切换；自定义中英文；法术/装备拖拽自动翻页；宝石价格及类型；两主职后加子职；预备调整与外部拖入；兼职法表/DC/攻击；拖拽响应；子职版本筛选；后开兼职等级；服务器角色链路；场景选择响应；三龙牌落牌先于回合横幅。

## 已验证的修改

- DM 分配：工具栏新增“分配玩家”；后端验证 DM 身份。已验证分配、撤销、玩家自授予被拒、玩家导入后原有令牌所有权仍可用。真实枭熊房间待验证。
- 角色卡切换：远程阅读快照留在内存，不再对全部已加载卡片和头像反复做本机备份。相同持久版本复用文档对象，权限仍即时更新。
- 状态链路：缓存读取仍由服务器 CAS 防并发覆盖；自定义状态目录作为提交后的异步显示同步，不阻塞角色保存。
- 目录反馈循环：旧场景只补齐缺失的目录条目，不反复覆盖已有房间目录。两宿主测试目录写入 2355 次降为 8 次（后者包含权限分配等整个用例的写入）。
- 自定义条目：中文名、英文名、原始 JSON 中的 name / ENG_name 分开保存；浏览器重载后仍保持。
- 拖拽：法术切到法术页、物品切到背包页；减少幽灵元素样式复制和落点重复计算，允许兼容的父级接收区接住拖拽。实际手机手感待验证。
- 多职业：每个主职业有单独子职入口；导入职业使用恢复的原来源识别子职和法表，2014 / 2024 不混并。
- 预备法术：Wiki 法术可直接拖入预备栏；测试 8 → 9 → 26，上限 26 拒绝第 27 项。无法复现的具体“护盾术”卡仍需真实资料确认，不声称全职业规则自动化完成。
- 兼职施法：可按职业筛选法表、分别显示施法属性/攻击/DC；人工攻击/DC 修正目前共同生效，预备数量仍共用现有角色设置。
- 子职版本：职业正文中嵌入的子职也遵守 Wiki 的版本筛选。
- 后开兼职：已有级别模型通过“先填职业，再启用兼职”的检查，5 + 3 = 8；没有添加把不明等级自动猜成某职业的迁移。用户具体旧卡待验证。
- 服务器：增加同房间无内容通知，原上传目录与当前房间分别处理；CAS、库存保护和隐私检查保留。HTTP/2 已开启。仍依赖枭熊的身份和棋子同步，不是完全移除枭熊。
- 场景棋子切换：使用独立选择与缓存链路，修复目录循环；真实房间的卡顿程度待验证。
- 三龙牌：横幅排队，等待最新牌桌版本完成落牌；WebGL 与 DOM 浏览器动画顺序检查通过，刻意移除等待条件后测试能抓出提前横幅。
