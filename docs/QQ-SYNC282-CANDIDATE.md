# QQ 卡库导入与在线接收更新 282 候选

单机版 QQ 账号二级弹窗加入角色卡搜索、刷新和“导入当前场景”。导入的是原五页编辑器中的云端卡；再次选择同一张卡打开已有副本，不替换待核对草稿，也不打开嵌套浏览器。账号退出与当前卡信息入口保留。

281 能将获准修改写回原卡，但单机版缺少接收其他端更新的定时流程；枭熊已缓存的非当前云端卡也会跳过后台读取。282 补上两处接收路径、同浏览器只读标签页的显示更新和卡库画廊的目录轮询。单机版每 5 秒读取轻量目录，只有版本变化才读取完整角色；枭熊保持 5 秒缓存及并发上限，未变化返回修订号和权限。

云端服务目录只查询名字、版本和角色权限，不解析完整卡片或内嵌头像。原卡 JSON 身份保留。接收更新前核对账号、本机内容散列和保存队列；两端均有修改时保留本机草稿并提示冲突。未确认的写入继续核对原回执，不能盲目重放。断线后的恢复独立于正常在线接收流程。

本批限定网站、卡库、新版插件 Suite-dev 和必要的云端目录读取优化。稳定插件、旧站导出、首页、三龙牌及玩家数据库不纳入更换。完整审计、生产页面浏览器检查、精确源码 CI、逐目标备份及公网复验完成前，本文件不代表已经上线。模拟账号和房间边界检查也不替代真人 QQ 扫码或真实多人房间验收。
