# Three-Dragon Ante 0.2.2-dev

已于 **2026-09-09 18:34（北京时间）** 发布到独立 Dev。[安装三龙牌](https://obr.dnd.center/three-dragon-ante-dev/manifest.json)。27/27 个公网文件内容、类型、跨域及页面缓存检查通过。

## 本次更新

1. 补全 40 类卡牌的中英文效果说明和 18 个选择提示，明确谁操作、从哪里拿牌或金币、数量、对象和生效时间。导览与练习用具体点数解释：领出者发动自己刚出的牌；之后比较自己刚出的牌与右边玩家本轮的那张牌，较小或相同才发动自己的牌。
2. 修复公开牌被区域装饰边框挡住、等待回执和翻牌中的公开牌不能查看的问题。等待其他人、空手和旁观时也能查看公开牌。固定说明后仍可悬浮其他牌，长说明可以滚动，房间刷新不会跳回顶部。对手的暗牌继续保密。
3. 加入金币、抽牌和翻牌音效，使用本地 Web Audio 合成。顶部可以开关音效并记住选择；同一次动作不重复播放。隐藏窗口、暂停或关闭会停声，同一浏览器的多个本插件窗口只由最近操作的窗口发声。
4. 每次能力触发时展示 1.5 秒：左侧沿用原来的矢量卡画，水平缓慢旋转共 24 度；右侧显示发动者、牌名和完整效果。开启系统“减少动态效果”时保留阅读时间，停止旋转。连续触发依次展示。
5. 展示结束后才开放相应选择，并呈现自动效果产生的抽牌或金币变化。等待选择或持续效果尚未结束时，公开来源牌保留金色光边；其他玩家的横幅说明谁发动、等待谁选择。借用能力和要求另一位玩家回应时，来源与操作人分别跟踪。
6. 教学对手会等待实际展示结束后再行动。隐藏、断线、换局或关闭时清理演出，不补播旧效果，不留下全屏遮罩。顶部横幅只保留当前牌名与等待者，完整操作说明放在选择面板中。

本次继续使用原有矢量图，无 AI 图片。银龙先知在手牌已满时的处理，说明中明确标作本牌桌现有裁定；没有借文案修改基础规则。

## 玩家测试清单

已经安装的玩家请完整刷新枭熊页面，再打开独立三龙牌。至少用两个玩家窗口检查同步表现。

- [ ] 查看抽牌、拿金币和交换牌的中英文说明，能读清楚来源、数量和对象。长说明能固定并滚动到最后一句。
- [ ] 进入“我的牌什么时候发动能力”练习：出较小的黑龙会发动自己这张牌；撤回后改出较大的金龙，不应发动其抽牌能力。
- [ ] 等待对手或等待选择时，悬浮双方公开牌、下注牌和正在翻开的牌。固定一张说明后，仍能查看其他牌；不能看到对手暗牌。
- [ ] 检查金币收付、抽牌和翻牌的声音；关闭音效后三类都停止，再打开应恢复，同一次动作不要叠播。
- [ ] 两位玩家同时观看触发：左侧矢量牌轻转，右侧显示牌名与完整效果，约 1.5 秒后结束。展示期间不能提前选牌或继续出牌。
- [ ] 用狗头人、银龙先知等需要选择的能力检查：正确的玩家可以选择，公开来源牌保持发光，其他人能看到正在等待谁；结束后光边和提示应更新。
- [ ] 试用预言家借用能力、黄铜龙要求右边玩家回应：分清发动者、选择者和收款者，连续能力依次显示，私有候选牌不向其他人公开。
- [ ] 在演出和等待选择时切回地图、隐藏或关闭牌桌，再打开。应没有残留黑罩，不重复演出、出牌或扣币。
