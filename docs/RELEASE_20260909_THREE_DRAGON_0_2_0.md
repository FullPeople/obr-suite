# Three-Dragon Ante 0.2.0-dev

已于 **2026-09-09 16:30（北京时间）** 发布到独立 Dev。安装：[Three-Dragon Ante 0.2.0-dev](https://obr.dnd.center/three-dragon-ante-dev/manifest.json)。27/27 个公网发布文件核验通过。

## 更新内容

- 真实三维酒馆牌桌：有厚度的双面卡牌、底部扇形手牌、分席位的对手牌背，以及金银筹码堆。
- 保留原来的几何矢量龙图和 III 牌背。不使用 AI 图片，也不下载卡面图集。
- 普通暗置和出牌改为直接拖拽：拿起、曲线指引、松手、翻转和落牌。暗置牌放在自己面前，统一揭示前保持牌背；不再显示下注或普通出牌确认按钮。
- 卡牌等待对应的主持端回执后落定。消息丢失可以重试原操作，普通状态刷新不会延长本次等待期限，也不能替代出牌确认。
- 四页规则与区域导览，接入 41 个本机实操练习。仍使用同一套 Legendary Edition 基础规则；练习不影响房间牌局。
- 对手能看到悬浮和拿牌姿态，消息只包含手牌序号。关闭、换局和取消操作会清理相应状态。
- 保留键盘操作、低动态效果与 WebGL 不可用时的 DOM 牌桌。舞台静止、隐藏或导览打开时停止连续渲染。

## 建议测试

DM 在房间安装 [三龙牌 Dev](https://obr.dnd.center/three-dragon-ante-dev/manifest.json)。已经安装的房间请各端完整刷新枭熊页面，再打开独立三龙牌按钮。

1. 先开“如何游玩”，逐页查看区域说明并进入实操练习。核对矢量卡画、文字、窗口关闭和返回牌桌。
2. 至少两名玩家入座。分别从手牌拖一张到自己的暗置槽中心，确认只有牌背落在本人面前；全部暗置后再揭示和计算金币。
3. 轮到自己时拖牌到自己的公开牌阵。向别人的槽、公共暗置区或桌外拖牌应回到手中，不提交操作。
4. 一端悬浮、拿起并取消手牌，另一端应只看到相应牌背的姿态，不能看到牌面。松手成功后每端应只有一张对应场上牌。
5. 按方向键选牌、空格拿起、Enter 放下、Esc 取消。拿牌期间换局或改变合法行动，旧拿牌应取消。
6. 短暂断网或关闭并重开牌桌，确认不会重复扣币或重复出牌；出现“重试这次操作”时再次发送同一个操作。关闭界面仍保留座位，主持人关闭整个浏览器时其牌局会暂时不可用。
7. 测试 2～6 人、全屏与紧凑窗口，检查暗置槽是否被手牌遮挡、文字能否通过卡牌预览与桌面详情读清，以及动画是否顺畅。

联网通过枭熊房间消息；主持浏览器执行规则并在本机保存牌局。网站服务器不运行对局服务。自动测试采用真实浏览器、规则、渲染器及可控的枭熊接口；仍需要上述真实枭熊房间和玩家设备验收。
