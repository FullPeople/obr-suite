# 2026-10-14 · 投骰后续回执与中继断联修复

用户反馈第一次投骰立即播放，第二次按钮长时间不可用。服务器日志确认 nginx 写入请求临时文件时遭遇磁盘空间不足，导致 `/suite-dev/relay` 返回 500。上次发布遗留的失败副本及重复上传包共约 273 MB 已核对并回收，当前前端与回滚目录保留。

仅新版中继入口关闭请求磁盘缓冲，保留现有 HTTP/1.1、WebSocket 和数据大小限制。中继为不超过 4 KB 的未压缩小请求保留独立名额，避免投骰命令和回执排在大型消息后面；压缩与大型消息的原有并发及总内存限制保持。大型视图不能占满全部队列预算，小型回执保留空间；断开客户端的过期视图可重建，命令与结果回执不丢弃。重复请求状态和回执按 requestId 合并。

定向测试覆盖两个大型请求占用时连续两次回执、视图队列容量满时仍能送回执、断开客户端视图回收、命令和回执保留，以及只改变新版中继入口的配置与幂等性。部署仅更新中继程序和 nginx 对应入口，不重建角色卡、稳定插件或 2D 前端；前端仍为 1.0.292-dev。
