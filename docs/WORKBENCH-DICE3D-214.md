# 新版骰子 214：皮肤展示与常驻加载

仅修改新版 `/suite-dev/`。保留线上 213 角色卡/relay 修复，不发布旧 `/suite/`、独立角色卡、Web Lab 或任何服务端变更。

## 本轮合同

- 皮肤页用五个材质按钮：瓷质、拉丝金属、猫眼石、半透明树脂、卡通涂鸦。删除漫画、水墨、霓虹选项；已有这三种选择显式迁移为卡通，并通知玩家重新选择。
- 下方用只读 3D 转台展示七骰，复用实际 GLB、UV、shader、玩家颜色。它不创建 Controller，不掷骰、不记历史、不广播。只在进入皮肤页时加载，离开时暂停动画。
- 表达式输入关闭浏览器自动补全/提示，↑ 回看历史、↓ 前进并恢复未发草稿，不抢占 IME 或带修饰键的输入。
- 中央累计总数使用提交时的玩家颜色与对比描边；骰子字体、飞值和拖尾不因此换色。
- 预测结果只能提前返回给内部提交调用，不能进入可见/持久化历史。整次提交的全部子公式动画完成后才入列；中途打开任何 UI 也不能提前获取历史。暗骰继续严格按权限分发，公开不会重放骰子。
- 常驻后台在 SDK ready 时立即启动骰子与历史，不依赖打开角色卡、骰盘或旧模块开关。初始化 Promise 去重，先安装结果监听再加载渲染层。
