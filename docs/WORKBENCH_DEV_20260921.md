## 连接和权限

只用同浏览器窗口 postMessage，无新增同步后端。消息校验 origin、WindowProxy、随机会话；请求有 ID 去重、棋子绑定 / 场景代次校验，数值写入先比较旧值。每次读取和写入重新检查角色权限；怪物权限沿用 GM 或棋子拥有者。旧加载结果不能替换新选择；选择变化取消未完成的资料读取。

关闭入口 iframe 不会断开；角色窗口刷新由后台心跳恢复。房间页面重载后必须重新点击入口建立新会话。复制地址到独立浏览器或另一设备不构成连接。后台暂停、平板休眠和跨浏览器连接未实现自动配对。

整卡 PUT 沿用现有服务；写前比较远端文档以拒绝已知冲突，但此接口没有原子 ETag/CAS，不能保证多个客户端同时提交无冲突。即时数值也不能把 SDK 普通更新当作跨客户端事务。
