# 恢复新版工作台的资料导入和订阅入口

旧设置页已有本地 JSON／Markdown 导入和单文件 URL 自动订阅。新版工作台重组设置分类时，“规则资料／Wiki”只保留两个开关和怪物来源控件，把原本的资料区域过滤掉了；数据模块仍在，但用户无法从这个入口导入或订阅。修复前的真实编译设置页在 GM 身份下找不到 URL 输入框，原五秒断言失败，记录保留。

候选复用原设置页的两个资料区域及原事件处理，接在怪物来源控件之后。GM 可导入本机文件、添加原始 JSON URL、刷新和移除订阅；玩家保留原只读范围。沿用现有 IndexedDB、来源校验、刷新失败保留缓存及更新事务，没有新增另一套来源或存储协议。

实际编译页面回归使用原创资料和独立浏览器，覆盖 URL 添加、原生文件选择、更新失败、重试、更换内容后无重复、重开、无关本机文件保留、390px 入口及玩家只读。既有怪物来源开关、选书、保存失败恢复及窄屏检查也须一并通过。完整配对构建、准确提交 CI 和合并后检查另列；受控 SDK 夹具不代表真实房间或玩家原设备验收。

该入口修正不改变已回放的 25 个原生资料消费文件，也不改变 Web／Data 的 77 个规则绑定文件。最终使用哪份现有回放，仍须核对完整来源字节和冻结输入；未解析资料、上游失效地址及玩家原格式缺失继续单列。当前未部署，邮件和私人资料没有进入仓库。
