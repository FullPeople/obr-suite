# QQ 卡库入口修复候选

新版工作台位于独立标签页。此前“我的 QQ 卡库”在原枭熊房间页打开弹窗，当前标签页看起来没有反应。277 将卡库显示在当前工作台内，关闭后返回之前的工作区。

卡库沿用 QQ 连接、本人原卡加载、默认锁定、解锁后房间自动写回和重新锁定功能。工作台通信只提供 QQ 房间卡信息与当前玩家 ID。登录会连接当前玩家自己的插件后台，由云端核对账号；个人凭据不会写入房间信息，其他成员不会收到它。

新增受限通信检查，并从实际构建的工作台点击入口、连接账号、加载五页编辑器和关闭返回。测试使用合成账号与房间接口；真实枭熊房间的现场验收单独记录。只发布 `/suite-dev/`，最终 CI、回滚备份和公网结果以发布回执为准。
