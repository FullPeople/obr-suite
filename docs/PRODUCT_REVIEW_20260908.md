# Full Suite 优化与新增需求评估

更新：2026-09-08。最终工作目录为 `U:\枭熊插件\obr-suite`；源码来自用户指定的共享目录，保留完整 Git 历史。线上正式版 1.2.2、dev 1.0.148-dev 是功能基线。两个频道的运行代码已从历史提交重新构建并与线上校验，详见 [版本依据](DEPLOYMENT_BASELINE_20260908.md)。

本轮完成版本整理、线上与源码审计、公开资料研究和实施方案。下表中的新功能仍是待实施项；没有以构建成功代替真实玩家验收，也没有部署新功能。共享源码的最后四个提交包含未上线的优化，保留在迭代分支，不混入正式版源码基线。

## 应先优化的日常体验

1. **先有反馈，再补齐数据。** 怪物库现在等所有启用来源的整库读取结束才显示；搜索预览又会先等待书名等辅助数据。慢来源不能拖住正常来源，面板应先显示标题、缓存结果和可操作的骨架，再补内容。详情与 `_copy` 依赖按需求加载，限并发并为来源提供超时、重试和上次可用缓存。
2. **开关状态必须真实。** 目前模块按顺序启动，异常后仍可能标为已开启，启动中的开关变化还可能丢失。应先修正启动/停止状态收敛、错误提示和重试，再测量是否值得拆包。不能直接把全部模块改为无限并发或串行动态下载。
3. **选择角色时更新同一块面板。** 减少 HP、状态、资源和信息弹窗同时出现。快速换角色不反复销毁、打开 iframe；异步结果必须检查当前目标，防止把 A 的编辑写给 B。
4. **设置按用户任务组织。** 建议“我的体验 / 房间规则 / 内容与扩展 / 高级”，玩家默认只见能操作的项。常用设置放功能旁，教程默认折叠。正在编辑的 URL、名称和焦点不能因为别人改了房间开关而丢失。
5. **减少重复读取，但保留数据新鲜度。** 血条的后台和页面都对无关场景事件刷新。应只处理相关对象、合并重复工作并带场景/请求代次；不能把进入防抖前的旧快照覆盖到新状态上。

已存在的搜索索引预计算、迷雾空间索引、差异提交、部分功能按需加载继续保留。这些是最新源码已有成果，不重复包装为本轮优化。实际打开速度尚未在真实 Owlbear 房间测量；归档中的体积数据不代表用户端延迟。

## 界面与多插件边界

- 主入口只呈现少量日常任务；复杂选项逐步展开，保存偏好，禁止每次重开都重复配置。
- 关闭界面只停止界面绘制；音乐、牌局、持久展示的业务状态由明确的常驻拥有者维护。动作栏同时显示能力与后台生命周期分别验证，不靠反复强开弹窗保活。
- 优先单套件解决。只有播放或小游戏的独立生命周期、安装入口确实有收益时才拆扩展；不为每个按钮建立一个新插件。
- 设置→内容与扩展提供可复制的 manifest 链接、用途、启用状态与恢复入口。不要承诺浏览器脚本能静默替用户安装扩展；也不要把“复制链接”标为已经安装。
- stable/dev 当前共用元数据与工具 ID，同一房间只装一个频道。新伴随插件使用独立 ID，不能复制迷雾/状态的常驻写入职责。
- “静默失效”应有状态与一次重试：已连接、需点击启用声音、功能失败、房间未就绪，含可定位日志；避免每次进房连续弹多条提示。
- 不能保证浏览器关闭整间 Owlbear 房间后还持续执行，拆成另一个 iframe 本身也不能突破浏览器播放和后台节流规则。

## 分批实施与验收

**第一批：稳定与易用。** 模块生命周期、首屏反馈、慢来源隔离、设置草稿、HP 面板目标一致性。先测 cold/warm 打开和慢源失败，再挑最小改动。首个可见反馈暂定 100ms 内、热开可操作暂定 300ms 内，均为待真实环境确认的设计目标，不是本轮成绩。

**第二批：日常新增。** 队伍共享视野、Boss 血条、休息/传送转场。加入玩家 A/B 隔离、隐藏 NPC、迟加入、切场景、关共享即时收回、多 Boss、减少动态效果测试。

**第三批：完整英文与音乐。** 英文不是换按钮文本：2014/2024 模板、下载、编辑、导入/覆盖、法术/物品/怪物说明、角色卡服务、所有错误回退都验收。音乐先通过多人开播、换 action、关闭控制面板、重连、发起者退出，再开启全员操作。

**第四批：三龙牌与指针/跟随原型。** 基础盒规则、私有手牌与权威服务齐备后做 2 人和 6 人完整对局；关窗、重试、重复命令和断网不丢局。鼠标和跟随分别测宿主选择、测距、画图等模式边界。

**最后：历史迷雾。** 先写明记录语义和版权来源；墙后不泄漏、离屏移动、开关门、传送不探索中间路径、个人历史隔离通过后，才衡量分块存储、FPS、内存和存档体积。

每批保留 DM + 两名玩家真实房间验收、明暗主题、断线重连；构建和纯算法测试只是其中一部分。现有跨模块清单中仍未完成的验收继续保留。

本次验证：两个历史部署源码及最新迭代源码的 TypeScript/Vite 构建通过；最新迷雾算法自检 **52/52**；配套角色卡自动资源 ID 测试 **11/11**。最新迭代的启动路径压缩体积工具输出约 **112.4 kB / 33 chunks**，这是构建文件估计，不是房间打开速度。迭代分支将 npm 包及锁文件的旧 1.0.7 元数据对齐到 1.2.2，未改变依赖版本。
