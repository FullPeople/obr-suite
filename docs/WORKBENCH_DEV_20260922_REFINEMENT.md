## 行为变更

1. 保存成功响应附带服务器合并后的角色和场景快照。客户端在结束乐观编辑前接收此快照；快照与目录带递增序号，旧响应不可覆盖新值，宿主刷新后通过启动标识重新建立序号。未完成保存时不发布中间快照。修复资源 2→0→2→0 的回跳。
2. 怪物检定与豁免只使用能力 / 技能名称；动作投骰仍使用动作名称。
3. 怪物生命条去除整条深蓝背景，收缩靠左并保留 130 px 最小血条宽度。血量、临时生命、护甲沿用原组件的红 / 粉 / 盾形语义，锁定按钮保持可辨。输入接受绝对值、相对加减和简单算式，使用套件原有解析与限制。
4. 主骰盘与二级骰盘仍复用原功能，以独立工作台样式覆盖为灰蓝色、扁平按钮和紧凑边框；不修改 stable 原骰盘。
5. 共享角色簿支持有编辑权限的角色删除，二次点击确认。删除服务端文件，清理当前场景 / 房间目录及棋子绑定；棋子本体保留。房间删除记录阻止旧场景目录将该卡恢复。客户端不能直接调用中继的宿主删除入口。
6. DM 资源管理改为并排紧凑卡片：生命 / 上限 / 临时 / 护甲算式输入，次数点选、进度条左右半区消耗与恢复、加减、补满、添加、编辑、移除及生命条锁定。资源修改落到 native 角色、兼容旧卡的资源字段和场景 metadata；法术位 / 生命骰字段同步。
7. DM 控制台、投骰放在角色选择行最前方；左侧切换工作区，保留右侧 Wiki 的 DOM 与阅读位置。DM 首次打开进入控制台，选中绑定棋子仍可切到对应卡。
8. 从套件设置同步 allowPlayerMonsters、searchGmOnly 和相应模块开关。玩家禁用图鉴时删除图鉴分类、搜索结果及已打开的怪物正文；GM-only search 时隐藏右侧 Wiki。设置变化后无需重开网页。该行为是界面可见性，不声称已从浏览器中清除曾读过的公开规则数据。
9. 修复时停结束写入后展开旧 cluster-row 被开发版错误转换成 action.open。转场的短休 / 长休 / 文字、目标玩家、预览 / 播放、减少动态选项直接显示在控制台，使用原转场模块和广播。默认传送特效快捷开关沿用原“本机偏好”；每扇门明确指定的效果继续按其设置执行。音乐与完整设置仍打开原界面，迁移留待后续。
10. 纸卡支持双指缩放（1–3.5 倍）和双指移动，A4 逻辑尺寸不变、右侧不缩放；提供还原按钮，抑制缩放后的误点并取消气泡 / 头像拖动。内容框可单指滚动。普通点按仍可打开投骰调整。
11. 投骰 RPC 不再排在角色文件保存队列之后；身份、角色权限及外观等只读数据批量初始化，真正的投骰与权限仍在宿主验证。表达式框上下方向键浏览最近 50 条成功投骰表达式，下键回到尚未发送的草稿。
