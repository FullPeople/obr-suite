## 性能边界

先前固定构建研究的计算中位数减少约 16%～23%，详见 [SIMD 研究结果](DICE-JOLT-SIMD-RESULT.md)。当前浏览器一轮 SIMD 测试的较慢一端可见读回约为：首次八枚混合骰 0.42 秒、热八枚 0.41 秒、无目标面板 0.38 秒、19 枚三次预测 1.20 秒；普通版相邻一轮分别约为 0.62、0.60、0.38 和 1.88 秒。丢失目标场景 SIMD 约 0.62 秒、普通版约 0.49 秒，没有一致提速。

这两轮来自有并发工作负载的同一台 Windows 电脑、两个 Chromium 上下文、真实 GPU 读回与模拟 10 ms 网络，样本不足以证明完整链路的稳定提速比例。它们不是显示器呈现、真实 Owlbear 房间或玩家线路测量。**不能承诺任何情况下 0.3 秒出骰**，复杂重算仍可能较慢。真实多人房间、手机、Safari、Firefox、ARM 和自然缓存升级继续待验收；研究首轮 SDK 心跳超时的原因仍未确认，本轮混用检查未重现。
