# 盾牌英文选项的工作簿迁移

两版工程副本现在把真正的盾牌装备输入 AS40 改为 `No`，下拉列表改为 `Yes,No`。AC、盾牌重量和导出 JSON 的来源随之迁移，旧中文“是／否”仍兼容。工具从两份固定原卡重新生成，原卡及公开下载不变；这还不是完整英文角色卡。

## 可重复生成

```text
python -B -X utf8 tools/xlsx-localization/shield_package.py
python -B -X utf8 tools/xlsx-localization/selftest_shield_package.py
```

默认创建仓库相邻 `_audit/xlsx-export-package/shield-candidate-*` 新目录；也可用 `--output-dir` 指定该审核根内尚不存在、名称以 `shield-candidate-` 开头的目录。输出包含原件快照、AV1 工程种子、最终副本和 `shield-report.json`。不覆盖既有目录或文件，不写入 `public/`，不访问外链目标。

新工具以规范 LF 后的散列加载已发布的 `export_package.py`，校验和执行的是同一份读取字节，并复用它加载的公式生成器。通过该工具的 `prepare/build` 从固定原卡生成种子，再核对种子整包散列。它不依赖开发机盘符、某次历史审核目录或审核脚本。

## 改动范围

- 主表 AS40 从共享字符串“否”变为独立内联字符串 `No`，避免影响使用同一共享字符串的其他输入。
- 仅把 `AS40:AT40` 从原共用验证中拆出，使用 `Yes,No`；其他地址的验证规则、属性和覆盖范围保持。
- 主表 D23 同时接受“是”和 `Yes`；数据表 AN56（2014）／AO58（2024）同时接受“否”和 `No`。
- Export A178 从错误的 AS41 改读 AS40，保留拼接空字符串的行为。实际导出图和完整 JSON 哨兵检查确认该引用只负责 `combat.shield.equipped` 字符串；其他导出公式、schema 与 ruleset 不变。AC 和重量仍通过前述计算链响应装备状态，不能把保留其他原缓存的 JSON 比较当成整卡重算结果。
- 删除所有工作表公式单元格的 `<v>` 缓存，包括空缓存和共享公式格缓存。其余公式正文、属性及非公式输入不变；外链部件及其缓存按原字节保留。
- 只给 AS40 新增专用样式：取消换行并启用缩小适应，原字体、字号、颜色、边框、对齐及保护属性保留。其他同样式单元格不变，合并区域、行高和列宽不变。

样式表原有声明数小于实际节点数：2014 为 1007／1012，2024 为 1108／1111。因此新索引按实际数取 1012／1111，新的计数为 1013／1112；全部 2,123 个旧样式节点逐字保留，不把原错误计数当成可用索引。两版各有七个其他单元格使用原共享样式，它们的原 XML 保持。

实际原件的数组范围共 368／1,862 个，均为单格；没有 dataTable 或多格数组范围。工具检查并拒绝需要另行处理的无公式缓存 follower，不能把这个拒绝检查说成真实多格原件测试。删除的公式缓存为 5,538／7,160 个，其中含原有 78／85 个错误缓存；错误缓存消失不代表原公式或外部依赖已修复。

## 已取得的证据

冻结逻辑原型通过作者 29 项结构检查和 88 个有限输入场景。另一代理使用自己的 XML 定位、公式解析和求值器，通过 28 组独立检查、32 个有限输入场景及六个有效变异；旧新重量及 L60 的八个比较是现有场景子集，不重复加总。

样式变体通过 30 项增量检查，独立审阅另验证全部旧样式、14 个共用单元格和八个合法 XML 变异。主代理查看了两版的 Yes／No 四张最终预览，均为完整单行，右侧下拉箭头保留。独立审阅还查看两张旧 Yes 裁切图。图片来自 Artifact Tool，未对原卡进行整本导出或保存。

原型、样式变体及独立证据分别保留在 `_audit/2026-09-08/xlsx-shield-workbook`、其 `style-variant` 和各自的独立审阅子目录。原型期间的验证器定位错误、旧样式计数假设失败及预览批处理内存压力均保留记录；这些失败不计为通过，也未通过修改工作簿来掩盖。

便携集成工具及最终固定树的检查结果见进度文档第十八批与 `_audit/2026-09-08/phase18-validation`；原型和便携工具的来源、运行及计数分别记录。

## 未完成的验收

这些副本没有在 Excel／WPS 中打开、重算、保存并重新导入。原本依靠缓存读取的消费者，在原生重算和保存前会缺少数据；因此文件名明确包含 `NO-CACHE-NOT-FOR-UPLOAD`，报告保持 `native_recalculated=false` 和 `upload_ready=false`。

有限公式模型使用其他输入的原缓存，不能证明整卡计算、外链更新或原生显示。原空白装备输入仍按旧公式计入重量 6；大小写变体按有限模型兼容，首尾空格不自动裁剪，未知值也未新增推断。前端原有的空／零盾牌加值门槛与工作簿、服务端仍不是统一的新协议。

完整英文正文应用、富文本、剩余下拉和查找链、全卡布局与真实上传继续单独推进。本批不发布英文下载、不部署服务端或线上 stable/dev，也不把工程副本变小当成角色卡加载提速。
