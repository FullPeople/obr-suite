# 角色卡服务端中英文工作表别名交付

2026-09-08。实现位于项目旁边独立的 `character-cards-server`，本项目保存[便携补丁、验证器和测试](../../tools/server-patches/sheet-aliases-20260908/README.md)。没有复制服务配置、数据库、整套服务端或完整旧 parser，没有新建 Git 仓库，也没有部署服务。

## 本次解决的依赖

解析入口先结合明确的规则标记、已知旧版标题和工作表结构识别角色，再把每个角色的实际页名提供给原有消费者。中英文唯一角色可以混用，缺关键页、同角色双页、规则冲突或跨版本语义混用会拒绝，不再因为页名改成英文而静默失去法术正文或背包内容。

2014 的个人页是 `背景 / Background`，资料页是 `背景数据 / Background Data`；2024 的个人页是 `起源 / Origin / Origins`，资料页是 `背景 / Background Data`。`Origin` 是已审核名称，`Origins` 保留先前审计提案的别名。`Races/Species`、`Strongholds/Bastions` 也按版本处理，并检查同语义重复。

原有 JSON `schema_version:0.3`、字段、AV1 overlay、数值处理和 HTTP/HTML 代码均未改变。仅 AV1 提供布局证据时，也不借此修改原 `meta.ruleset` 输出。现有中文原卡的完整解析结果保留。
