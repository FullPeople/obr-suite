## 文字与依赖范围

新增 `main-display-labels-001.jsonl` 共 342 条正式定位审核，其中 321 条单元格文字、21 条输入说明。根完整审阅全部 199 个源组，结合此前标签记录选择具体位置。全卡累计 **10,146 条内容已审核**，仍有 **13,345 条／767,892 原文字符**未译，长文 2,613 条／605,355 字符。126 条原有种子本批经明确审核，没有直接计为已审。

正文区分每级额外 HP、法术点、无消耗法术及不同规则版本的熟练措辞；原 2014 表已有 Heroic Inspiration 字样不擅自校订。保留作者 Beiling 署名；E4 的实际玩家名没有改成英文。输入说明保留 X、O、🅞 的区别及原公式所在工作表，不因显示英文化重命名公式引用。

先核对原件及当前工程副本的单元格、展开共享公式、名称、条件规则和输入验证。C13:C18 属性键、2014 技能查找键、职业/种族默认输入等共 **90 个主卡位置**暂缓，包含此前已处理的 AS40 No；不能只替换可见文字而破坏查找。公式中的整列或打印区域引用仅作范围线索，不算逐格有效依赖证明。

## 保留式应用与最终版式

第一层在 207／226 个选定静态格应用完整英文，并按现行验证节点绑定 11／10 条说明。插入过的验证节点不能继续按原件序号猜位置。仅主卡 XML 和共享字符串改变，追加 129／148 个唯一字符串。

实际预览发现完整英文在原中文列宽下多处换行或截断，因此该第一版没有通过布局验收。第二层逐格采用完整文字或已审短写，使用 Arial 8–10 点字体、明确的居中和换行行为；不全局缩小字号。204 个短标题增加完整英文输入说明。B、F、P、W、AP 五列从原窄列宽调整为 4，其余列、行高、合并范围、图片和批注保持。五行高的 HP 侧标采用两行字母，避免在极窄列中挤成一行。

## 实际计算及可见结果

隔离 Calc 26.8.0.3 将卡片以无保存位置的可编辑内存副本打开，关闭宏及外部更新；原件和工程卡均未保存。

完整标题阶段分别比较两版每个模型的 9,300／11,492 个实际公式格。原生两轮的顶层结果均未标为全通过：第一轮漏列了原 `网页导入!B8` 对 `主要!$AV$1` 的直接镜像；第二轮比较器未排除原数据页的随机骰式。后续直接读取源公式核对：2024 原 80 个 RANDBETWEEN 格中 67 个结果不同，前后值都在各自原 d6/d8/d10/d12 范围，数据页 XML 未变。其余差异仅属于导出文字及其 AV1/B8 镜像。全部其他已比较公式值保持；这项事后差异审阅没有重跑已完成的整卡检查。原导出器会把某些标题当成 features/wondrous 等内容的问题仍待修复，没有把它记为本批解决。

最终短标题版另实际读取全部 433 个标题、字号、锁定状态、204 个完整说明及原 21 条说明。原生合并区域的宽度与实际字体文字测量均符合；AV1 有效 JSON、版本标识及 B8 镜像正确。该轮客户端、Office 均正常退出，没有超时。只验证主卡增量，没有重复全工作簿错误扫描。

PDF 使用明确 Selection 和当前主卡打印区域；第一次未正确传递 UNO FilterData 的预览导出了整本 82 页，已排除，不作为视觉证明。正确导出后，每版主卡均为一页。依据 [LibreOffice PDF 参数](https://help.libreoffice.org/latest/en-US/text/shared/guide/pdf_params.html) 设置选区，几何来自原生 [SheetCellRange](https://api.libreoffice.org/docs/idl/ref/servicecom_1_1sun_1_1star_1_1sheet_1_1SheetCellRange.html)。

根查看了两份实际最终主卡图。最初 PDF 预览器将原批注画成大图标，容易误认为表内按钮遮挡；2024 PDF 的 58 个注释对象确认来自原批注。隐藏 PDF 注释标记后核对文字布局，没有移动原卡图片或批注。验收只覆盖已改主卡标题在 Calc PDF 中的排版，不代表 Excel/WPS、真实提示弹窗、其他页、玩家输入后的长文本或完整英文内容通过。

## 独立生成与证据

`main_display_package.py` 从仓库固定原件、正式审核及布局配置生成两份作者计划。Artifact 只新建单独文字表，实际回读 1,632／1,820 格；适配器验证全部值、原件和上游输入后生成卡片。新的输出目录必须位于指定审核根内且不存在；拒绝 Python 优化模式。

本轮重新导出两份作者表，独立入口生成的两包与实际原生验收文件逐字节一致。随后在新来源目录复制所需工具和原件，以明确给出的上游输入及作者表再次重建；不读历史审核文件或全局 catalog。错误上游文件、两个作者表的实际 D2 文字变异、输出越界、已有目录和优化模式均在创建候选目录前拒绝。复制作者表用于第二次重建，没有声称第二次 Artifact 导出或重复原生计算。

隔离来源共 22 个文件，九次实际命令包括两次成功准备/构建、六项要求的拒绝及一次无效变异夹具。检查器先因优化模式错误提示大小写不同而停止，直接审阅已留错误确认正确拒绝；之后变异夹具使用 XML 编码名 utf8，使含中文的 XML 无法读取，不计为目标文字拒绝。修正夹具为 utf-8 并先验证 XML 有效，只恢复两项缺失的作者变异检查；未重跑成功构建，全部原输出与失败记录保留。应用器不需要因这两个夹具问题修改。
