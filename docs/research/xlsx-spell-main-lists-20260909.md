# 主卡法术下拉与空白项

主卡现有的已知／准备法术输入改用有界列表，保持原输入位置和选择范围。已制作两版实际工程副本：2014 原已知列表中的空白被收拢；2024 已知列表与两版准备列表复用原有紧凑结果。重复法术和原有顺序保留。当前不改公开下载，尚未验收原生 Excel/WPS 点击下拉、重算和保存后上传。

## 实际验证

根计划的 22 个有限场景与另一代理的 16 个原生产公式场景分别记录；后者实际核对每版 359 个 F/K 公式及共享／数组属性。有限求值覆盖空白、重复、稀疏和首尾值，不等于 Excel 引擎或普遍错误传播证明。

审计包原型通过 7 个正向／稳定性检查和 12 个有效 XML 变异。独立应用审阅用另一套标准库解析器读取实际种子和候选，核对全部已有格、402／2 个辅助、3／2 个验证、每版两个名称及 64／68 个非目标部件；4 个真实名称的空表端点检查和 4 个有效 XML 变异通过。没有把此前计划测试计入包应用的独立数量。

便携移植保留五个核心函数的相同语法树，根另审仓库定位、依赖加载、输出边界和实际生成调用；两个新入口在加载前拒绝 Python `-O`，避免跳过断言。最终 [便携检查](../../tools/xlsx-localization/spell_main_lists_selftest.py)有 19 项检查、9 次真实命令调用：从仅含九个工具和两份原件的新隔离目录生成计划及两版副本，另有七次指定拒绝。独立窄比较确认实际输出与已审包完全相同，未重复运行或累计旧包测试。
