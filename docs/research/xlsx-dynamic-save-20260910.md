# 保存后的多行文本与英文卡上传

两版英文工程卡的原输入在保存后仍然完整。问题发生在公式导出和导入叠加阶段：Calc 把引用文本中的换行/制表符压平，解析器随后用这份 AV1 JSON 覆盖已经正确读取的角色显示名。第七份服务器补丁保留已知自动导出卡的原始身份文字，修复文件上传路径中的覆盖问题。它不是完整英文卡发布，也未安装到服务器。

输入使用第三十六批伙伴页工程卡，SHA256 分别为 `59313e07baf22cdaea26d8df79a5ffddb1021de3975e2b67b23673754d11a324`、`58b1fb5cac29a971e4fbba4c6d8e00e35ff9fb8264a6d7a5f68800cec0c00ab6`。源卡仍在 U 盘，未改动。
