# 主卡导出字段定位修正

第二十九批修正原角色卡 AV1 中已经确认的错误引用：消耗品表头不再导出成奇物，物品数量不再来自旁边的技能值，货币读取实际金额格，特殊能力读取两版各自真正的五个输入行。改动已应用到工程副本，两版实际 Calc 的这些字段检查完成。动态文本中的换行和制表符另发现兼容失败，因此没有宣称整轮导出或正式下载通过。

## 从原件确认的范围

读取两份固定原件的导出表达式，建立 JSON 字段到原单元格的对应；原式分别引用 264／284 个位置。正式原件、现行工程副本和主卡实际可见布局共同核对。A1 作为模板署名元数据保留，不把正常标题元数据误判为坏引用。

| 字段 | 原错误 | 修正 |
| --- | --- | --- |
| 奇物行 | L42:L52 多读了第 52 行消耗品表头 | L42:L51 十行 |
| 奇物数量 | I42:I51 是旁边技能表 | 每个条目代表一件；这张表没有数量输入列 |
| 消耗品数量 | I53:I57 是技能数值 | 左侧数量输入 AP53:AP57 |
| 2014 特殊能力 | BT40:BZ45 落入魔宠区域 | BT33:BY37 的名称及 BZ33:CO37 的说明 |
| 2024 特殊能力 | 多含第 45 行空白隔行 | BT40:BY44 的名称及 BZ40:CO44 的说明 |
| PP / GP / EP / SP / CP | AN60、AG60:AG63 多为币种或栏目标题 | AP59、AI59、AI60、AI61、AI62 |

AP 数量右侧的 AS 输入保持原样，本批既有 JSON 的 qty 字段读取左值，没有擅自将右值改作现存数量或新增字段。2024 战斗风格仍为 BT33:BZ37 五个条目。AS40 的盾牌装备状态延续前批修正，没有重新退回原 AS41。

运行时从实际原件检查栏目文字、合并边界、70 个可编辑输入和相邻技能公式，再按精确表达式结构调整三个列表。数字字段保留原 ISNUMBER 行为：空白、数字形式的文字和布尔值不伪装为数值；零、负数与小数不擅自改规则。

改动限于这些已确认字段。原 armor.name=H40 等其余可疑映射、服务端解析器的同类位置配置继续校准，不认为本批已经覆盖完整导出结构。原玩家数据和公开中文模板保持。

## 生成与独立核对

使用原来已经固定散列的 JSON 导出编译器，保留字符串转义、输出长度限制及溢出明确失败行为。只重建既有隐藏 Export 页并替换主要 AV1 的公式；不新增工作表或改表名。任何其他部件直接引用 Export 内部格都会拒绝，防止移除旧内部格时破坏外部消费者；现有网页导入 B8 继续通过 AV1 获取结果。

两份独立作者表存放待写公式的文字，实际回读 **3,460／3,872 个格**。最初把以等号开头的内容直接写入 values，Artifact 当成公式计算并报告不存在的工作表；没有导出卡片。随后按其文本接口要求加单引号作为输入前缀，真实导出值仍为不带前缀的原表达式，并逐格核对，不是用作者表计算代替整卡计算。
