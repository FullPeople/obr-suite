# 主卡 Yes/No 开关迁移

在已核对的主卡导出副本上迁移五个原默认值：两版 BQ1 平均生命骰和 X20 英雄激励，以及 2014 的 H39 万事通。默认分别为 Yes／No，使用原已审译文。2024 H39 使用 O/X，既有 AS40 盾牌已支持 Yes/No，这两项继续保持。

先读取当前两包的全部公式、展开共享公式、名称和规则，共 9,799／11,717 个表达式节点。准确单格引用对应 2014 的 19 个计算公式和一个条件谓词、2024 的一个计算公式和一个条件谓词；X20 没有直接公式引用。9／18 个 OFFSET 表达式逐一读取，均是其他资料页的下拉范围。整列或范围引用没有被当作该单格的有效读取证明。

平均生命骰计算的 No 分支和 2014 万事通的 Yes 判断增加原中文／英文双语比较；两条平均值高亮谓词同样处理。两个已有下拉列表改为 Yes/No，原范围、严格校验属性和提示策略不变。原中文值继续具有计算含义，原生诊断通过程序给单元格赋值验证；这不表示中文文字属于新的英文下拉选项。

每版只有主卡 XML 改变：2014 共 22 格，包含三个默认值和 19 个公式；2024 共三格，包含两个默认值和一个公式。另各有一条下拉表达式和一条条件表达式改变。其余主卡格、样式、布局、共享字符串、对象、旧提示、隐藏页和 AV1 保持原字节。最终两卡：
