# 图片工具入口与关闭恢复

原生图片工具只有中文标题，页内关闭又直接关闭宿主窗口，后台的已打开标记没有同步清除，下次点击可能需要两次才能重新打开。第十四批在保留工具和窗口 ID 的基础上修正入口和关闭流程。

工具说明按当前中英语言用相同 ID 更新，不注销或激活工具，不重开正在处理的图片。首次角色/连接读取、原生注册与清理遵守会话顺序；降为玩家会隐藏 GM 入口并关闭其编辑窗口，之后成为 GM 可以恢复入口。旧回执不会删除新会话的入口或窗口。

宿主可能已经应用新语言但回复失败，因此每次派发前撤销旧的已确认标签缓存；之后切回原语言仍重新提交同一 ID，避免界面一直停在失败请求的语言。此路径以先应用后拒绝的 SDK 边界复现，并保留编辑窗口及草稿。

每次打开带新的随机窗口标识，页内关闭通过本机消息让后台代办。后台核对同一玩家连接和当前窗口；真正关闭成功后才清除标记，所以页面在宿主回执前被销毁也不丢关闭结果。旧窗口和其他玩家消息无效，消息只有窗口/请求标识，不带图片或草稿。

关闭失败保留窗口和同页重试，丢失本机回执在五秒后恢复关闭按钮，不持续循环。错误提示暂时使用标题原有空间，不挤压画布或遮挡模式按钮；关闭失败或切换其语言不会改变当前画布像素和裁剪范围。旧版直接打开的编辑 URL 保留原生关闭路径。

清理失败向现有模块管理器报告，保留精确的待清理会话；重试只处理仍归其所有的入口或窗口，完成后才允许新会话注册。不会在宿主拒绝删除时宣称停用成功，也没有改动全局模块管理器。

专项工具使用实际模块、已安装 SDK 的 Tool/Popover/Player/Viewport/Broadcast API 和真实 ModuleLifecycle。窗口组合工具在 Edge 中运行实际后台与处理 iframe，让受控宿主先销毁 iframe 再返回 close 回执，并核对当前画布像素。原处理页像素、裁剪与上传回归仍独立保留。

```text
node tools/circle-image-entry-selftest.mjs --verify-mutations
node tools/circle-image-window-selftest.mjs
node tools/circle-image-locale-selftest.mjs
```

最终固定源码、检查数量和构建结果记录在进度文件。本机受控 SDK/浏览器组合并非实际 Owlbear 房间，原生相同 ID 显示刷新、真实资产和房间行为仍需宿主验收。
