# Full Suite-dev 1.0.173

本轮网页、库存宿主和资源组件配套升级。产品细节见随附 Web 源码包 `docs/WORKBENCH-173.md`。

## 宿主变更

- 状态恢复不向存储行补写 `_suiteStatusId`；网页对 Wiki/场景显示名中的图标差异归一化，保留选择行 ID。
- 库存转移、拆分、引用和排列支持立即投影与宿主确认。宿主保留有界操作历史，撤销仅比较并回退本次触及的行，保留不相关并发改动；过期内容、锁定、占用格子和伪造客户端恢复凭证会被拒绝。
- 公共计数保留在同一持久账本的资源区域，默认物品网格 4×5，不混排。新增数值无上限与资源锁定字段，保持旧资源兼容。
- 总览区分角色/怪物，只展示场上绑定资料；怪物资源写入棋子 metadata，角色资源仍写入原角色文档并镜像棋子。
- DM 静默模式也作用于资源通知。锁卡的无权限接收端仅显示「玩家恢复/消耗了什么」，不显示数值与资源名。此为产品显示权限，不声称 OBR metadata 或广播对恶意客户端加密隔离。
