# Owlbear Suite 后续更新计划（玩家版）

这轮更新会分批进行，不会再把几十项改动一次性塞进正式版。每一批都会先放到 dev 测试，确认没有明显回归后再进入下一批。

## 我们准备改什么

1. **状态显示更稳定**
   - 减少状态气泡反复刷新、闪烁、重复出现或突然消失。
   - 多个人同时操作时也尽量避免互相覆盖。

2. **角色卡资源不再串数据**
   - 修复中文技能或能力可能共用同一个资源编号的问题。
   - 不同能力的次数、进度和恢复会各管各的。

3. **传送门第一次拖动也要可靠**
   - 修复刚进入场景后，第一次拖动角色可能没有正确触发传送的问题。

4. **变身规则更清楚**
   - 已经处于变身状态时，不能继续套娃变身。
   - 老版本已经产生的数据仍然可以正常解除，不会直接作废。

5. **怪物资料排版更准确**
   - 法术会正确放进动作、附赠动作或反应，不再全部挤在错误的位置。
   - 怪物图片统一改用更稳定的 kiwee 图片源。

6. **角色卡编辑更好用**
   - 武器编辑区域不再挤出窗口。
   - 长名字、中英文和窄窗口下都能正常点击、输入。

7. **玩家权限更可靠**
   - 设为“仅主持人可见”的搜索栏不会在切场景或重连时短暂出现在玩家画面上。

8. **先攻提示更明确，也不会剧透**
   - 轮到你时会有提示，快轮到你时会提醒准备。
   - 隐藏中的单位不会通过提示顺序暴露。
   - 提示不会挡住画面和鼠标操作。

9. **投骰结果、动画和记录保持一致**
   - 主持人用于测试和裁定的固定结果工具会严格限制在合法点数范围内。
   - 玩家看到的骰子、动画、历史记录和最终结果必须一致。

10. **整体界面跟随 Owlbear 主题**
    - 明亮主题和黑暗主题都会重新检查。
    - 普通窗口保持清晰，透明特效层不会再变成整屏黑色遮罩。

## 更新方式

- 先更新 dev 测试版，不直接动正式版。
- 每批只处理一类问题，完成后进行多人房间实测。
- 如果发现黑屏、卡顿、权限泄漏或数据错乱，会暂停下一批，先解决根因。
- dev 经过实际跑团验证后，再发布到 stable 正式版。

如果你愿意协助测试，最有价值的反馈包括：发生时间、当时使用的功能、DM/玩家身份、是否刚切换场景，以及截图或录屏。
