## 本次新报错：blocks.map is not a function

责任与原因：上轮添加职业起始装备显示时，把 `startingEquipment.entries` 优先当正文读取。但背景的 `startingEquipment` 通常直接是数组，数组自己有一个 `entries()` 方法。代码把这个方法当成内容，再调用 `.map()` 就报错。一份合集只要含一个这样的背景，整个文件都不能进入 Wiki。重试会重复执行同一段坏代码，所以不能自行恢复。

改动：先区分数组和对象。数组直接读取；对象里的 `entries`、`default`、`defaultData` 仅在确实为数组时使用。没有删除背景、跳过报错文件或吞掉异常来伪造成功，也不需要清空角色数据或上游 JSON 缓存。

漏测原因：上轮覆盖了职业的对象格式，却没有让背景的数组格式经过新增分支。新测试同时覆盖混合集合、空数组、2014/2024 职业格式、后台 Worker 和无法使用 Worker 的回退路径。
