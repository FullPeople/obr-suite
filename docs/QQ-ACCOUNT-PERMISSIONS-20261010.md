# QQ 卡库与房间原卡编辑候选

角色卡面板新增“我的 QQ 卡库”。在网站登录并确认连接后，只能加载本人所有的云端卡。加载默认锁定；卡主解锁后，房间成员的修改自动写回同一张云端原卡。卡主可重新锁定或移出房间，移出不会删除原卡。

个人会话只保存在插件页面，不写入房间信息。房间保存的授权凭据只针对该张卡，有效期为 7 天；重新加载会换凭据并重新锁定。枭熊客户端没有提供服务端可验证的成员证明，复制的凭据在失效或撤销前可读取该张卡，解锁时也可编辑。服务端始终检查原卡版本和当前锁定状态。

开发版工作台同时支持 QQ 房间卡；背包直接写回原卡，跳过旧公共库存账本。稳定版通过独立的 QQ 卡库和五页编辑器加载与编辑，不移植整个开发版工作台。

失败、冲突和结果不明确时保留草稿；先核对云端，不盲目重发。QQ 卡暂不接入旧公共库存的转移或赠予。额度、账号授权和原浏览器临时卡迁移由配套 Web 后端负责。

本候选使用隔离工作区和精确配套的 Web 源码。浏览器检查使用本地数据库、合成账号和模拟枭熊接口，不向线上写入角色数据；不能据此声称真实 QQ 或真实房间验收完成。尚未发布到 `/suite-dev/` 或 `/suite/`。
