# 第二轮实测反馈修正

用户本轮反馈取代旧路线中的共享指针和内置三龙牌方向：共享指针取消；三龙牌成为独立扩展。当前候选版本为 Full Suite **1.0.150-dev** 和 Three-Dragon Ante **0.1.0-dev**。本记录的发布证据将在实际部署和公网核验后填写；候选版本号本身不表示已经上线。

## 交付内容

- 音乐仍由枭熊原生后台页面播放，没有额外挂一个近乎不可见的操作弹窗。关闭控制窗不会结束背景音频；关闭整个枭熊页面会结束该页面音频。Music Studio 与房间双向确认播放、暂停、进度、循环等状态，网站静音只改变网站自己的音量。
- Boss 改为原生鼠标穿透的透明全屏展示层，在下方居中显示；使用 Accessibility 名称，与普通 HP 共用阈值。实际展示后才隐藏该 token 的普通 HP，AC 保留。按本插件已打开面板避让，距离底部可调，无关闭按钮；从 token 关闭。未知外部扩展的位置仍需真实房间检查。
- 玩家没有转场入口。短休采用篝火与钟，长休采用帐篷、月亮与太阳，自定义文字伴随篝火，均为有限动画并支持减少动态效果。CG 支持所有非 CHARACTER 图像层，先黑条后图片渐变，延迟内容和旧关闭操作有生命周期保护。
- 传送门房间默认图可由 DM 从原生图库选择；新门使用此图，图像失效回退内置图标。已有门保留各自图片。未设置偏好的怪物和角色悬浮窗默认开启，保留用户明确关闭的选择。
- 三龙牌使用独立 manifest、原生 action、命名空间和本机牌局存储；主插件不加载牌局引擎。全屏木色酒馆牌桌、扇形手牌、倾斜牌背与公开牌、有限发牌/落牌动画；公开手部动作只同步手牌位置。41 个本机教学练习使用真实规则引擎，含整局、基础及特殊牌。

## 网络和边界

三龙牌的座位与广播使用枭熊，规则运行和 IndexedDB 保存由牌局主持人的浏览器承担。自有服务器只托管网页，没有新牌局转发或计算服务。主持人完全离线时不会自动迁移主机；浏览器存储丢失也没有云端存档恢复。音乐网站配对仍使用原有 PeerJS 控制连接，音频由各客户端直接加载媒体地址。

原有共享指针和内置牌桌的运行注册、设置开关和快捷入口已取消。自动审批拦截了旧源文件删除/移动，因此历史目录仍留在本地及 Git 中，被 TypeScript 和构建入口排除；独立牌桌采用复制后迭代的源码。这些旧文件不参与运行。离线英文 XLSX 草稿与角色卡服务器继续留在原有暂停范围。

## 验证与实测

已完成的验证包含真实浏览器 DOM/WebAudio/WebCrypto/IndexedDB 和模拟 SDK 边界；没有真实枭熊双端房间、原生 modal 共存、实际图库和大地图帧率的验收结论。逐项实测见 [第二轮测试清单](DEV_TEST_CHECKLIST_20260909_FEEDBACK.md)。

- 主插件入口：22 个设置页视图、12 个常用栏宽度；玩家无转场按钮、无共享指针、独立牌桌仅有安装链接、默认悬浮窗偏好均通过。
- Boss：实际浏览器展示层与鼠标/滚轮测试边界、6 个针对性变异、6 组普通 HP/AC 联动、22 组缩放计算检查通过；避让采集器 9 组及实际搜索/性能窗口开关 6 组通过。只计算已打开的本插件面板，关闭页面后迟到通知不再写入；角色资料自行改变高度时按保守高度避让，搜索结果展开区域暂未精确测量。外部扩展位置和宿主 modal 并存尚待真人验收。
- 音乐：19 组真实 Studio 页面、音频及房间同步检查通过。一次相同源码的复跑在快速新增音效步骤超时，已保留失败记录，随后完整重跑通过；不能用此结果代替房间音效及自动播放实测。
- 转场/CG：20 组转场协议检查、15 组 CG 检查、23 组 Edge 页面检查，以及各自 10/6 个针对性变异通过。初始化失败、旧场景返回、加载图片失败和关闭重试均有覆盖。
- 三龙牌：260 条 UI、52 条沉浸布局断言；41 个教学练习的 45 组规则覆盖、12 组浏览器检查及 5 个变异通过。手势包含 12 组协议、4 个变异和 8 组双页面实测；25 组独立入口/真实牌桌/教学集成通过。加密私有视图、持久化、完整规则回放和关闭重开回归亦通过。
- 传送门：31 个后台场景和 30 条编辑页面断言覆盖图库、默认回退、旧读取和旧窗口关闭迟到、跨场景创建和布局重置。关闭需要匹配本机连接和具体窗口实例，失败后可重试。

部署前将使用锁定依赖和已提交源码重新构建，校验所有发布文件，更新 dev 与独立三龙牌 dev、Music Studio 的相容前端文件。稳定版 Suite 和角色卡服务器不在本轮发布范围内。
