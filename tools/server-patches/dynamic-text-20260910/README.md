# Preserve source text when importing calculated English cards

LibreOffice 26.8 can flatten newline/tab characters in referenced formula text
while retaining the full text in the saved XLSX input cells. The existing parser
reads those cells correctly, then its optional AV1 JSON overlay overwrites the
display name with the flattened formula result.

This seventh patch recognizes only the two bounded Export-sheet expressions
generated by our reviewed character-card compiler. It retains the sheet-parsed
identity text for those expressions. Numeric overlays still apply. Handwritten
JSON, other AV1 formulas and legacy workbooks retain their existing override
behavior. Optional reference quoting/absolute markers are accepted; changed
references, constants or schema are not classified as our generated expression.
The extra formula read is skipped for ordinary workbooks without the Export page.

Apply after `main-remaining-20260909`, whose exact output is
`457449293fd32bc45a409a8dd6109c34244ec53194d3bbb5b061969576479d03`.
All six prerequisite packages remain required when starting at the live baseline.
The manifest and `files.sha256` identify the complete delivered source.

```text
python -B -X utf8 apply_parser_patch.py apply --source <six-patch-parser.py> --output <new-parser.py>
python -B -X utf8 verify_delivery.py --source <six-patch-parser.py> --saved-result <native-save-result.json> --out-dir <new-validation-directory>
```

The verification input is the native save/reopen report documented in
`docs/research/xlsx-dynamic-save-20260910.md`; its two saved XLSX fingerprints
are checked. Tests include actual saved-file parsing, explicit overrides,
formula recognition, and unchanged unrelated parser functions. This does not
repair Calc's formula engine or the JSON manually copied from AV1/B8. The
original export payload remains available for diagnostics. Source XLSX files
are never modified by the parser.

This is a reviewable patch, not a deployed service or a complete English download.
