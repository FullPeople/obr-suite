# Safe dice resource verification

Only pushes to `fix/dice-safe-resources-20261004` start this workflow.
The regular Suite verifier also admits this branch. Paired Web is fixed to
`fb584043c6bed831b9ca92eab783653770c24fe6`.

Three dedicated browser jobs run in parallel, with read-only repository/Actions
permissions: complete recorded two-client behavior and genuine recovery injections,
real lifecycle/pause/retention/restart checks, and one uncaptured landscape
baseline/candidate/baseline comparison. The comparison keeps 1/2/5/9, 10-die
control, mixed-nine and percentile cases; every independent case must first observe
both real controllers and physics workers empty. It has no speedup acceptance
threshold and does not certify physical phone performance.

The capture job first verifies historical evidence from exact Suite
`3d596cbf032ad2afac0451866e98e885418e27e9`, successful six-job run
https://github.com/FullPeople/obr-suite/actions/runs/37233243394.
The reference's ten visual artifact identities/digests must still exist and must
not have expired. A failed/missing/wrong-SHA reference fails the guard.

The guard defaults to the complete tracked file inventory, including every build
import, root HTML, package lock, asset and unknown future dependency. Only docs/
and an exact, named list of this change’s CI/verification files are mutable. It independently verifies all 59 immutable asset locks without
normalization. File additions, removals, or any protected byte difference fail.

Controller end-to-end behavior is explicitly NOT inherited and its before/after
hashes are reported. In types.ts, only removal of the unique, known
Peer.inlineChunkV1/inlineRollV1 interface-field fragment is permitted. All remaining
bytes, including KINDS, ASSET_VERSION, url() and now(), must be identical. The safe SHA re-executes its own end-to-end capture, transport,
privacy, physics-state isolation and lifecycle jobs. It does NOT claim that all
45 end-to-end viewport cases were rerun on the safe SHA. The referenced evidence
is limited to the unchanged visual/physics/asset modules and layout behavior.

The prior evidence is already materialized and inspected: 30 raw RGBA pairs match
byte-for-byte, 45 viewport cases passed, and explicit context recovery, preview
reopen and transparent clear PNGs exist. Selected inspected PNG hashes and artifact
links are in `dice-visual-reference-3d596.json`; the parent also reviewed them.

If any inherited dependency changes or the reference expires, regenerate relevant
visual evidence rather than weakening the guard. Existing first-run failures,
second-run results and mixed nine-die timings remain part of the experiment record;
no latency claim is inherited from the experimental inline-transport branch.
